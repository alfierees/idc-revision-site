Testing found two material failures. First, the initial answer to the lecturer-workbook question incorrectly said the workbook agreed. The official-solution discrepancy existed in the site's assignment metadata but was absent from the retrieval corpus. The corpus now includes that note alongside the assignment setup question, and the corrected chunks were added to all three vector namespaces. Second, one marketing request returned an empty answer and one machine-learning response stopped midway through a formula. The API now limits answer length and retries empty or output-limited generations with reasoning disabled; it returns an error if the retry is also incomplete rather than presenting a partial explanation.

The final preview at commit `969a6b3` passed 117 tests and a complete Astro build. This is a six-prompt manual sample, not a statistical guarantee of correctness on every course question. The three chunking strategies were measured separately in [the retrieval report](rag-retrieval-report.md); answer generation remains a distinct, ongoing quality check.
