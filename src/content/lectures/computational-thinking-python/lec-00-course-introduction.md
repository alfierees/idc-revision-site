## Why take it, and what you should get out of it

The deck frames the course around three motives: **problem-solving and [[Computational Thinking]]**, **practical Python for beginners**, and **data manipulation and basic analysis**.

**Course goals**
- Understand core computer science and programming concepts.
- Learn Python basics and progress to intermediate-level programming.
- Grasp [[Data Structure|data structures]] and visualisation.
- Get an introduction to automation, AI tools and data analysis.

**Learning outcomes**
- Write and debug basic Python code.
- Automate tasks and perform data analysis.
- Build simple applications and scripts for business problems.
- Become familiar with AI tools for practical problem-solving.
