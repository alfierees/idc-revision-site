## 1. Base R graphics

The course does not study base graphics, but the deck names four functions: `plot()`, `hist()`, `boxplot()` and `pie()`.

## 2. The Grammar of Graphics

[[ggplot2]] implements the [[Grammar of Graphics]], published by Wilkinson in 2000. A figure is built from layers:

| Element | Meaning |
| --- | --- |
| **data** | The underlying information |
| **aes** | [[Aesthetic Mapping\|Mapping]] of data to visual properties |
| **geom** | The [[Geom\|shapes]] that represent the data |
| **facets** | Multiple panels |
| **stats** | Statistical transformations |
| **coords** | The plotting space |
| **themes** | Visual styling |

## 3. The basic pattern

```r
library(tidyverse)

ggplot(data = <dataset>) +
  aes(<mappings>) +
  <GEOM_FUNCTION>()
```

Using the `mpg` data, plot highway mileage against engine displacement:

```r
ggplot(data = mpg) +
  aes(x = displ, y = hwy) +
  geom_point()
```

![[intro-r-l09-scatter.png|640]]

`ggplot()` and `aes()` alone draw only empty axes. The geom tells R what to draw.

## 4. More aesthetics

```r
ggplot(data = mpg) +
  aes(x = displ, y = hwy, color = class, shape = drv) +
  geom_point()
```

![[intro-r-l09-color-shape.png|640]]

The legend is created automatically.

## 5. Bars and histograms

[[geom_bar()]] counts a categorical `x`, so do not map `y`.

```r
ggplot(data = diamonds) +
  aes(x = cut) +
  geom_bar()
```

![[intro-r-l09-bar.png|640]]

Mapping another category to `fill` stacks the bars:

```r
ggplot(data = diamonds) +
  aes(x = cut, fill = clarity) +
  geom_bar()
```

![[intro-r-l09-stacked-bar.png|640]]

[[geom_histogram()]] shows the distribution of a numeric `x`. Use `binwidth` to set the bin size.

```r
ggplot(data = diamonds) +
  aes(x = price) +
  geom_histogram(binwidth = 1000)
```

![[intro-r-l09-histogram.png|640]]

## 6. Adding layers

Layers are added with `+`:

- `ggtitle()` for the title and subtitle
- `xlab()` and `ylab()` for axis labels
- `theme()` for individual visual properties
- `theme_bw()` and similar for a complete theme

```r
p <- ggplot(data = mpg) +
  aes(x = displ, y = hwy, color = class, shape = drv) +
  geom_point()

p + xlab("Displacement (L.)")
```

A plot can be saved in a variable and extended later.

## 7. Combining with dplyr

Pipe data into `ggplot()`, then switch from `|>` to `+`:

```r
mpg |>
  filter(drv == "4") |>
  ggplot() +
  aes(x = displ, y = hwy) +
  geom_point()
```

> [!warning] `|>` before `ggplot()`, `+` after it
> Data steps use the pipe. Plot layers use the plus sign.

## 8. Gapminder examples

The `gapminder` package holds country data on life expectancy, population and GDP per capita.

**GDP per capita over time:**

```r
library(gapminder)
countries_of_interest <- c("Israel", "Netherlands", "United States")

gapminder |>
  filter(country %in% countries_of_interest) |>
  ggplot() +
  aes(x = year, y = gdpPercap, color = country) +
  geom_line(linetype = 2) +
  geom_point() +
  theme_minimal() +
  xlab("Year") +
  ylab("GDP per capita") +
  ggtitle("GDP per capita by year", "Israel, Netherlands and USA (1952 - 2007)") +
  theme(panel.grid = element_blank())
```

**Wealth and life expectancy in 2007:**

```r
p <- gapminder |>
  filter(year == 2007) |>
  ggplot() +
  aes(x = gdpPercap, y = lifeExp, size = pop, color = continent) +
  geom_point() +
  xlab("GDP per capita [$]") +
  ylab("Life expectancy") +
  theme_bw()

p + scale_x_log10()                        # logarithmic x-axis
p + scale_color_manual(values = 1:5)       # colors by number
p + scale_color_manual(values = c(
  Africa = "black", Americas = "maroon", Asia = "gold2",
  Europe = "darkgreen", Oceania = "#00B2FF"))
p + ggthemes::scale_color_colorblind()     # colorblind-friendly
```

Run `colors()` to see R's built-in color names.

## Summary

- Every plot follows **data + aes + geom**.
- `aes()` maps columns to visual properties.
- [[geom_bar()]] counts categories and [[geom_histogram()]] bins numbers.
