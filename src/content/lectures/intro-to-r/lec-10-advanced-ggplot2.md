# Advanced ggplot2

> Part of: [[Intro to R]]
> Key concepts: [[ggplot2]], [[geom_col()]], [[Facet]], [[geom_smooth()]], [[ggplot Theme]], [[coord_flip()]]

Source: Moodle deck `lesson_10_more_ggplot_ENG.pdf` (20 slides). The figures below were regenerated by running the slide code in R.

## 1. Setting a default theme

```r
library(ggplot2)
library(dplyr)
theme_set(theme_minimal())
```

`theme_set()` applies a [[ggplot Theme]] to every new plot. The exam instructions require exactly this line.

## 2. Reference lines

`geom_abline()` draws the line $y = a + bx$, where $a$ is the `intercept` and $b$ is the `slope`.

```r
p <- ggplot(mpg, aes(x = displ, y = hwy)) + geom_point()
p + geom_abline(intercept = 30, slope = -3, linewidth = 2, color = "steelblue")
```

![[intro-r-l10-abline.png|640]]

> [!note] Updated argument
> The slide uses `lwd = 2`. Current ggplot2 uses `linewidth`, so the code above uses that.

Horizontal and vertical lines:

```r
p <- ggplot(mpg, aes(x = displ, y = hwy)) + geom_point()
p +
  geom_hline(yintercept = mean(mpg$hwy)) +
  geom_vline(xintercept = mean(mpg$displ))
```

> [!warning] Typo on the slide
> The slide's `ggplot(mpg aes(...))` is missing a comma after `mpg`. It is corrected above.

## 3. Columns and labels

[[geom_col()]] uses a `y` value you supply, while `geom_bar()` counts rows. Use `geom_col()` after summarising.

```r
mpg |>
  group_by(drv) |>
  summarize(hwy = mean(hwy)) |>
  ggplot() +
  aes(x = drv, y = hwy, fill = drv) +
  geom_col() +
  geom_label(aes(label = round(hwy, 1), fill = NULL), show.legend = FALSE)
```

![[intro-r-l10-col-label.png|640]]

`geom_label()` needs a `label` aesthetic.

## 4. Axis text

```r
p <- mpg |>
  ggplot(aes(x = manufacturer, y = hwy)) +
  geom_point()

p + theme(axis.text.x = element_text(angle = 45))
p + theme(axis.text.x = element_text(angle = 90, size = 15))
p + theme(axis.text.x = element_text(angle = 90, size = 15),
          axis.text.y = element_text(size = 15))
```

The default axis text size is 10 points.

## 5. Flipping and axis breaks

[[coord_flip()]] swaps the x and y axes. Scale functions choose which numbers appear:

```r
p + coord_flip()
p + scale_y_continuous(breaks = seq(10, 50, 5)) + coord_flip()
```

## 6. Facets

A [[Facet]] splits one plot into a panel per category. Read `~class` as "by class".

```r
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_wrap(~class)
```

![[intro-r-l10-facet.png|640]]

Two variables give a panel for each combination:

```r
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_wrap(drv ~ cyl) +
  theme_bw()
```

## 7. Trend lines

[[geom_smooth()]] adds a line that describes the data. Its default is **LOESS**, or **GAM** for large datasets. Use `method = "lm"` for a linear regression.

```r
ggplot(data = mpg, mapping = aes(x = displ, y = hwy)) +
  geom_point(mapping = aes(color = class)) +
  geom_smooth(method = "lm") +
  ggtitle("Linear regression line")
```

![[intro-r-l10-lm.png|640]]

## 8. Extensions

Many packages extend ggplot2. The deck demonstrates a word cloud with `ggwordcloud`, and says some of the code is beyond the course:

```r
library(ggwordcloud)
ds <- read_csv("ds_salaries.csv")
data_words <- ds$job_title |>
  strsplit(split = " ") |>
  unlist() |>
  table() |>
  as.data.frame()

ggwordcloud(data_words$Var1, data_words$Freq, random.order = F, rot.per = 0)
```

## Summary

- Use [[geom_col()]] for values you have already calculated.
- Use [[Facet|`facet_wrap()`]] to compare groups in separate panels.
- `geom_smooth(method = "lm")` adds a regression line.
- `theme()` controls text size, angle and other styling.
