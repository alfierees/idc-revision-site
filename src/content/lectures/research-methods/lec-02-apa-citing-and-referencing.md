# Lec 02: APA Citing and Referencing

> Part of: [[Research Methods]]
> Key concepts: [[APA Style]], [[In-Text Citation]], [[Reference List]], [[Et Al]], [[DOI]], [[Plagiarism]], [[Secondary Source]]

> [!info] What this note covers
> The course handout "Citing, Quoting and Documenting Sources" (APA 7th edition, edited by Dr. Orly Idan, November 2021) and the sample reference list. It is a reference sheet: use it while writing.

> [!quote] The core idea
> Ideas are the products of the academic world, and credit is the currency that buys them. Presenting someone else's idea without saying it is theirs is theft.

## 1. In-text citations

Give the author's surname and the year in parentheses.

| Situation | How to cite |
|---|---|
| One author | (Cohen, 1988) or Levy (1982) argued that... |
| Two authors | Both names, every time: (Bergman & Rappaport, 2021) |
| Three or more authors | First author + [[Et Al\|et al.]]: (Smith et al., 2010) |
| Several sources together | Alphabetical, separated by semicolons: (Becker & Cohen, 1981; Levy, 1979; Smith, 1984) |
| Year is part of the sentence | In 1981, Barnea published his book... In this book, Barnea argues that... |
| Same author again, shortly after, same paragraph | No need to repeat the year |
| Two authors with the same surname | Add the first initial: D. Levy (1983) and G. Levy (1985) found that... |
| [[Secondary Source]] | Original in the text, secondary in parentheses: (Levy, 2000 in Cohen, 2020). The secondary source goes in the bibliography. |
| No specific author | The organization or first words of the title: (United Nations Report, 2010) |
| Republished work | Original date / version read: (Smith, 1899/2002) |
| Direct quote | Quotation marks and the page: (Levy, 2009, p. 4) |
| Personal communication or interview | In the text only, **not** in the reference list |

> [!warning] Footnotes
> APA does not use footnotes for citing or referencing.

## 2. The reference list

The [[Reference List]] contains **every source cited in the paper, and only those**. To check this, read the finished paper from start to end and write down each source as it appears. Accuracy matters because the reader must be able to find the source. You do not state the type of source: the format shows it.

### Order of entries

1. Alphabetical by the **surname of the first author**.
2. A single-author work comes before a work by that author with others: `Levy, B. (1988)` before `Levy, B., & Cohen, A. (1969)`.
3. Works by an author with co-authors are ordered by the **second author's name**: `Levy, B., & Cohen, A. (1983)` before `Levy, B., & Tamir, H. (1967)`.
4. Same authors in the same order: by **year**. Same year: by the first letter of the title.
5. Different authors with the same surname: by **first initial**: `Cohen, B. (1989)` before `Cohen, H. (1984)`.
6. An institution as author is placed alphabetically by its name.
7. List surnames and initials for **up to 20 authors**.

### Formats

| Source | Pattern |
|---|---|
| **Journal article** | Al-Yagon, M., & Mikulincer, M. (2004). Title of article. *The Journal of Special Education, 38*(2), 111-124. |
| **Book** | Antonovsky, A. (1987). *Unraveling the mystery of health*. Jossey-Bass. |
| **Chapter in an edited book** | Culbertson, J. L. (1998). Learning disabilities. In T. H. Ollendick & M. Hersen (Eds.), *Handbook of child psychopathology* (pp. 117-156). Plenum Press. |
| **Conference paper** | Authors (Year). Title. Paper presented at the annual meeting of [body], [place]. |
| **Thesis** | Author (Year). Title. Thesis submitted for the degree of [degree], [school], [university]. |
| **Report without author** | The Central Bureau of Statistics (1985). *Title*. Publication details (Publication No. 7). |
| **Report with author** | Author, F. M. (Year). *Title of report* (Report No. XXX). Publisher. |
| **Newspaper** | Marcus, Y. (2006, October 24). The new era. *Ha'aretz*, Saturday Supplement, p. 24. |

> [!tip] What to check
> The order of the items, the hanging indent after the first line, commas, full stops, colons, parentheses, italics and capital letters.

## 3. DOIs and URLs

A [[DOI]] (digital object identifier) is a unique, persistent link to a work. It starts with the number 10 and has a prefix and a suffix separated by a slash.

- Format DOIs like URLs. The label "DOI" is not needed.
- Include a DOI for **every** work that has one, whether you read the print or online version.
- If an online work has both a DOI and a URL, use **only the DOI**.
- If it has a URL but no DOI, use the URL, linked as directly to the work as possible.
- A print work with no DOI gets no DOI or URL.
- Works without DOIs from most academic databases are referenced like the print version, without a URL or database name.
- A retrieval date is not normally needed. Add "Retrieved from" only when the date is required.

## 4. Online sources

| Source | Rule |
|---|---|
| Online abstract | Add `[Abstract]` after the title when you cite only the abstract |
| Online newspaper | Author (date). Title. *Newspaper*. URL |
| Online book | Include the publisher and URL |
| Encyclopedia or dictionary | Entry name first if there is no byline, `(n.d.)` if undated, plus a retrieval date |
| Interview | Not retrievable: text only, with the full date. Available online: use `[Interview transcript]` or similar |
| Online lecture notes | State the format in brackets: `[PowerPoint slides]` |
| Blog | Title of the post (not italicised) and URL. Use the screen name if there is no author name |
| Wikis | APA warns that wikis cannot guarantee verifiability or expertise |
