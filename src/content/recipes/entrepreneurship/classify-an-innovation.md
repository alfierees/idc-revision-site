Use this when you are given a scenario and asked which type of innovation it represents.

1. Ask who it targets. If it targets the market, it is **outward**. If it targets the organization itself, it is **inward**.
2. Ask what level it changes. If it is a practical, tangible change, it is **operational**. If it is an overarching, value-creating change, it is **strategic**.
3. Read the type from the grid: outward and operational is [[Product Innovation]], outward and strategic is [[Business Model Innovation]], inward and operational is [[Process Innovation]], inward and strategic is [[Management Innovation]].
4. Justify the answer using both axes.

## Common pitfalls

- Some scenarios can sit across two types. A mobile banking app is a customer-facing service, but it may also change how the bank delivers value, so state which reading you are using.

## Worked example

An AI inventory system is aimed at the organization's own operations, so it is inward. It improves how work is done day to day, so it is operational. That makes it [[Process Innovation]].
