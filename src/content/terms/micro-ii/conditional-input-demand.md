The cost-minimising input quantities $l(q_0)$ and $k(q_0)$ for producing output $q_0$, as functions of input prices and output.

## When to use

The output of the [[Cost Minimisation]] problem: solve for $l(q_0), k(q_0)$ first, then plug into $p_l l + p_k k$ to get the [[Cost Function]]. Can include corner cases where one input is zero.

See [[PS_03-Cost Minimisation & Properties of the Cost Function|PS 03]].
