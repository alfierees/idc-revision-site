The set of Pareto efficient input allocations between two firms: all points where their isoquants are tangent, i.e. $RTS_1 = RTS_2$.

## When to use

In production-economy questions, set $RTS_1 = RTS_2$ with the resource constraints to get the locus, then map it into output space to derive the [[PPF]]. In the lecture's examples this gave $k_1 = l_1$.
