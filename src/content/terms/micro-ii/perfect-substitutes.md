Technology $f=al+bk$ with linear isoquants. The firm uses whichever input has the higher $MP/\text{price}$ (a corner solution), switching abruptly when the ratio changes.

## When to use

Recognise it when the production function is linear: there is no tangency, so compare $RTS$ with $p_l/p_k$ and use the [[Corner Solution]].

See [[PS_03-Cost Minimisation & Properties of the Cost Function|PS 03]].
