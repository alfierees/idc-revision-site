The production function $f(l,k)=l^\omega k^\varepsilon$. Its [[RTS]] is $(\omega/\varepsilon)(k/l)$, so it has diminishing RTS and convex isoquants.

## When to use

The standard interior case in [[Cost Minimisation]]: set $RTS = p_l/p_k$ to get the cost-minimising ratio $k/l$, then substitute into $f = q_0$. If the exponents sum to 1 it also has [[Constant Returns to Scale]].

See [[PS_02-Isoquants, RTS & Properties of the Profit Function|PS 02]].
