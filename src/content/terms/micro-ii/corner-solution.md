An optimum on a boundary ($l=0$ or $k=0$), arising when the tangency condition cannot hold or would violate non-negativity. If $RTS > p_l/p_k$ everywhere on the isoquant the firm uses only labour; if $RTS < p_l/p_k$ everywhere it uses only capital.

## When to use

Check for it whenever the production function is linear ([[Perfect Substitutes]]) or quasilinear: compare $RTS$ with $p_l/p_k$ before assuming a tangency. Lecture example: $f=k+l$, $p_l=10$, $p_k=20$ gives $k=0$ and $C=10q_0$.
