A graphical tool showing all feasible allocations for two agents and two goods. Agent 1's origin is bottom-left, agent 2's is top-right (flipped), and the box has width and height equal to the total endowments of each good.

## When to use

Draw it for any [[Exchange Economy]] question: mark the endowment, the budget line through it with slope $-p_x/p_y$, indifference curves, and the [[Contract Curve]]. The lecture also reuses the same box for firms' input allocations in a production economy.

See [[Lec_04-Theory of the Firm, Partial & General Equilibrium|Lec 04]].
