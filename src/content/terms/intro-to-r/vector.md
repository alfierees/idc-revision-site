An ordered sequence of elements of one type, stored adjacent in memory. Lec 03 says it can hold numbers, strings or other data types, but only one type per vector.

## When to use

In Lec 03, `x <- 1:10` and `grades <- c(100,95,90,89,5)` are vectors, built with the [[Colon Operator]] and the [[c() Function]]. Arithmetic on a vector applies to every element, a [[Vectorised Operation]].

See [[Lec_03-Vectors|Lec 03]].
