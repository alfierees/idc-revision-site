A name that points to a stored value in R, created with the [[Assignment Operator]].

## When to use

Throughout Lec 02, for example `x <- 0.43`, and typing the name alone prints its value. A variable built from another, such as `y <- x*10^3`, is a snapshot, not a live formula (see [[Expression Evaluation]]), and it stays in the [[R Environment]] after the script runs.

See [[Lec_02-Variables and Assignment|Lec 02]].
