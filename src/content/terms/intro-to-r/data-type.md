The category of value R stores. Lec 01 lists four: [[Numeric]], [[Character]], [[Logical]] and [[Factor]].

## When to use

Whenever you read or write code, the type decides what a value is, for example `5>3` returns a logical value and a value in quotes is a character. In Lec 01 the script works through logical and character types in code, and [[Type Coercion]] converts between types.

See [[Lec_01-Data Types in R|Lec 01]].
