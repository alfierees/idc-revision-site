The [[Data Type]] for text, written as a string inside quotes, such as `"Ada"`.

## When to use

In Lec 01, `name <- "Ada"` and `surname <- "Lovelace"` store character values, and [[paste()]] joins them into one string.

See [[Lec_01-Data Types in R|Lec 01]].
