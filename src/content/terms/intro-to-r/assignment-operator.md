The operator `<-` stores the value on its right under the name on its left, so `x <- 0.43` makes a [[Variable]] called `x`. The Lec 02 script notes it is typed with Option and - on a Mac.

## When to use

Every time a script saves a value or a result under a name, as in `y <- x*10^3` or `lol <- c(grades,a)`. Typing an expression without `<-` only prints it and stores nothing.
