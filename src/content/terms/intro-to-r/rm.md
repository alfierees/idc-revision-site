Deletes a [[Variable]] from the [[R Environment]].

## When to use

In Lec 01, `rm("name")` removes `name`, and asking for `name` afterwards gives the error `object 'name' not found`. The variable comes back when the line `name <- "Ada"` is run again.

See [[Lec_01-Data Types in R|Lec 01]].
