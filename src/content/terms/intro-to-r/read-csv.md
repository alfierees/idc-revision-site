Reads a comma-separated file into a dataframe, with `header = TRUE` by default.

## When to use

Use it to load CSV data. Add `fileEncoding = "UTF-8-BOM"` if the first column name looks corrupted.

See [[Lec_04-Dataframes|Lec 04]].
