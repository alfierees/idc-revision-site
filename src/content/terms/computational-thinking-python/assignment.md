A statement that creates a [[Variable]] referring to a value, or rebinds an existing one, using `=`. For example `a = 5` stores 5 in `a`, and a variable can later refer to a value of a different type.

## When to use

Mixing up `=` (assign) with `==` (ask whether two things are equal) is one of the most common beginner bugs; see [[Comparison Operators]]. A line like `student_age =` with nothing on the right is an illegal statement.
