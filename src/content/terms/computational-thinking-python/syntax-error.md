Code the parser cannot understand, so it is caught before the program runs. Examples are `if a>5 print (a)` and a missing parenthesis in `print`.

## When to use

Lec 10 sorts errors into three kinds: syntax errors (parser), runtime exceptions (valid code, impossible action such as `1/0`) and logic errors (wrong result, no message). Syntax errors are always the programmer's fault.
