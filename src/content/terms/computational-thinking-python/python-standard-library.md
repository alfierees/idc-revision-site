The Python Standard Library is the set of modules bundled with Python, so no installation is needed. It covers the operating system, CSV files, random numbers, dates and times, and much more.

## When to use

The lecture samples six modules: [[math Module]], [[random Module]], [[datetime Module]], [[csv Module]], [[statistics Module]] and others. Anything outside it (such as [[NumPy]]) has to be installed with [[Pip]].
