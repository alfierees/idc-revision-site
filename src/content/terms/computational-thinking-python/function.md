A named, reusable block of statements that takes arguments ([[Parameter and Argument]]) and returns a value ([[Return Value]]). Names created inside it are [[Local Variable]]s.

## When to use

Functions are first-class values in Python (see [[First-Class Function]]); rebinding a parameter inside a function never changes the caller's variable.
