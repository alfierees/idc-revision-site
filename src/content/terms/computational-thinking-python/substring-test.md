The `in` operator applied to strings: it checks whether one string occurs inside another and returns a bool, with `not in` as its own operator.

## When to use

The match is case-sensitive and must be contiguous and in order, so `"ot" in "Introduction to Python"` is False even though `"to"` is found. The empty string is in every string, and every string is in itself.
