How the number of steps grows with the size of the input. Linear search needs up to n steps, binary search about log2 n (about 20 for a million items), selection sort about n squared and quick sort about n log n on average.

## When to use

Use it to compare algorithms and to justify choosing the built-in sort or binary search on a sorted list. The analysis is split into best, average and worst cases; PP 06 lists it among the key concepts.
