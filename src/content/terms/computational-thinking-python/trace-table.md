A hand-execution table with one row per variable change, used to follow code line by line and record each variable's value as it is calculated.

## When to use

Part B of the past papers asks you to fill one in and then write the console output. Typical traces are binary search (`low`, `middle`, `high`), bubble sort, selection sort and run-length encoding.
