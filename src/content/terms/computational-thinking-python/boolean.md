The type with only two values, `True` and `False`, written with a capital first letter (`true` is a `NameError`). It is named after the mathematician George Boole. Booleans behave as 1 and 0, so `4 + True` is 5, though the lecture advises against using them in arithmetic.

## When to use

[[Comparison Operators]] return a `bool`, and conditions in `if` and `while` rely on one. [[Any and All]] collapse a list of booleans into one.
