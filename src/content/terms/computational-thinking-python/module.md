A module is a file of Python code (any `.py` file) that can define functions, classes and variables, and can be used by another program through an [[Import Statement]]. A file `test.py` is the module named `test`.

## When to use

Modules split a growing program across files for simplicity, maintainability, reusability and scoping (each has its own [[Namespace]]). A module is loaded only the first time it is imported, and the [[Name Main Guard]] lets one file work as both a script and a module.
