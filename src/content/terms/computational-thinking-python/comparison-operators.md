`==`, `!=`, `<`, `>`, `<=` and `>=`, which compare two values and return a [[Boolean]]. Python also allows chained forms such as `8 <= int(c) <= 9`.

## When to use

Remember that `a = 5` is an [[Assignment]] while `a == 6` is a question, and mixed int and float comparisons use [[Coercion]]. Never use `==` or `!=` with floats, because repeated additions accumulate tiny errors (see [[Floating-Point Error]]).
