An operator is a symbol (`+`, `==`, `and`) that tells Python to perform a mathematical, relational or logical operation and produce a result. The values it acts on are its operands.

## When to use

This vocabulary appears when reading errors and expressions, for instance an unsupported operand type when `+` is used on an object that does not define it. See [[Arithmetic Operators]], [[Comparison Operators]] and [[Operator Precedence]] for the operators themselves.
