`readline()` returns the next single line of a file, and returns `''` at the end of the file.

## When to use

Each call moves on to the following line, so two calls print the first two lines and a call after the last line returns `''`. Compare with [[Read Method]] (whole file) and [[Readlines Method]] (list of lines).

See [[Lec_10-Exceptions and File IO|Lec 10]].
