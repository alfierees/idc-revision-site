`read()` returns the whole content of a file as one string, and returns `''` at the end of the file.

## When to use

Choose it when you want the file as a single string; use [[Readline Method]] for one line at a time or [[Readlines Method]] for a list of lines. Call it on the file object from [[Open Function]], normally inside a [[With Statement]].

See [[Lec_10-Exceptions and File IO|Lec 10]].
