A programming language is a formal language with strict syntax used to instruct a computer, unlike a human language. Most programs are written in high-level languages such as Python, Java, R, C#, C++, C, Pascal or Fortran.

## When to use

It is the starting point of Lecture 1, before [[Machine Code]] (what the hardware understands directly), the [[Interpreter]] and the [[Compiler]]. Python is a high-level, interpreted language.
