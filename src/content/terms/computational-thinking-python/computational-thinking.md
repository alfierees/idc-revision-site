Breaking a problem into steps that a computer can execute.

## When to use

Lecture 0 names it as one of the course's three motives, with practical Python and data manipulation. The sandwich-instructions exercise makes the point: the machine does exactly what you write, so steps that feel obvious must be spelled out, which is why Lecture 1 has you write [[Pseudo Code]] first.
