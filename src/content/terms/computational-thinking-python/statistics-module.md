A standard library module of basic statistics, including `mean`, `fmean`, `median`, `stdev` and `NormalDist`. `mean([1, 3])` returns the int `2` while `fmean` always returns a float, `2.0`.

## When to use

Use it for averages without writing the loop yourself. The lecture's example shows the median (3.0) ignoring an outlier of 1000 while the mean (251.75) is dragged up by it.
