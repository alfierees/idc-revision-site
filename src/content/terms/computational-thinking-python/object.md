An object is an instance of a [[Class]], a concrete thing with its own attribute values (the slide's analogy: the class is "Car", the object is "My Honda Jazz"). It holds both data ([[Attribute|attributes]]) and code ([[Method|methods]]).

## When to use

Each object created from a class has its own attributes, so `p1.weight` and `p2.weight` are separate. Objects are mutable (`p1.weight = 60`), and two different objects are not equal by default even if their attributes match.

See [[Lec_09-Classes|Lec 09]].
