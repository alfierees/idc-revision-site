The low-level language that hardware understands directly. A high-level program must be translated into it by another program: an [[Interpreter]] line by line, or a [[Compiler]] for the whole program first.

## When to use

Appears in the high level vs low level, interpreted vs compiled comparison; Java compiles to [[Bytecode]] rather than straight to machine code.
