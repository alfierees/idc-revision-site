A program that translates and executes source code line by line. Hardware only understands [[Machine Code]], so a high-level program must be translated; a [[Compiler]] instead translates the whole program first.

## When to use

Python is interpreted, which is why you can type one line at the `>>>` prompt and see the result immediately. Java is compiled to [[Bytecode]], which is then interpreted.
