A blueprint that defines the attributes and methods its objects will have. The class is the blueprint ("Car") and an [[Object]] is a concrete thing made from it ("My Honda Jazz"). A definition starts with the `class` keyword, as a function starts with `def`.

## When to use

Lecture 9 builds a `Patient` class around a BMI example, and the 2025 Moed A paper has an `Employee` class question. To design one, ask what [[Attribute]]s it holds and what [[Method]]s it offers.
