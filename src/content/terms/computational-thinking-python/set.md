An unordered, mutable collection of unique, immutable items. Duplicates vanish, it cannot be indexed or sliced, and an empty set is written `set()` because `{}` is an empty dictionary.

## When to use

Reach for a set when you need uniqueness, built-in union and intersection, or fast `in` tests, which work in about one lookup thanks to the hash table. Never rely on the order a set prints in.
