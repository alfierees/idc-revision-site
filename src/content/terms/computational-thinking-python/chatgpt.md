An AI language model developed by OpenAI that generates human-like text from context; GPT stands for Generative Pre-trained Transformer. Usage is simply input prompt, then ChatGPT, then output text. It is the lecture's example chatbot and a kind of [[Large Language Model]].

## When to use

Lecture 12 lists developer uses such as code snippets, code completion, bug detection and test automation. The notes add a caution that the model produces likely next words rather than guaranteed-correct code, so test anything it generates, for example with `assert` checks.

See [[Lec_12-Generative AI and Prompt Engineering|Lec 12]].
