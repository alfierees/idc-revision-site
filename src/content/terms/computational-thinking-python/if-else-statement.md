A [[Conditional Statement]] that runs the `if` block when the condition is `True` and the `else` block otherwise. Python evaluates the condition once.

## When to use

Two separate `if` statements testing a condition and its opposite are better written as one if-else; add [[Elif]] for more than two cases.

See [[Lec_03-Conditions and While Loops|Lec 03]].
