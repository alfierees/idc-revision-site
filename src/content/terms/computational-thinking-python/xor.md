Exclusive or: true exactly when the two inputs differ. Python has no built-in `xor` keyword, but `(a or b) and not (a and b)` and, for booleans, `a != b` both express it.

## When to use

Appears as a truth-table question in Lec 02: True xor True is False, which is the difference from `or`.

See [[Lec_02-Numeric Values and Strings|Lec 02]].
