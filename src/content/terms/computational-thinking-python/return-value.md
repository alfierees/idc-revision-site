The return value is what a call hands back to the caller; for `max(1, 2, 3)` it is 3. A function with no `return` statement returns `None`.

## When to use

This answers the exam question "what is the output of `print`?": it prints text as a side effect and returns `None`. A `return` exits the function immediately, so `return False` inside a loop stops the whole [[Function]].
