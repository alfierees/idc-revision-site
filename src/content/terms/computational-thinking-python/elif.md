Short for "else if": it builds a chain of conditions in which only the **first** true branch runs. It extends the two-way [[If-Else Statement]] to several cases.

## When to use

Because only the first true branch runs, the order of the `elif` tests matters; the lecture's character-classification example chains many `elif` tests in sequence.

See [[Lec_03-Conditions and While Loops|Lec 03]].
