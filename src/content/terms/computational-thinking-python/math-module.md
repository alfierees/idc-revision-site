The `math` module is a [[Python Standard Library]] [[Module]] of mathematical functions and constants, such as `math.sqrt`, `math.floor`, `math.ceil`, `math.sin`, `math.degrees` and `pi`. It ships with Python, so no installation is needed.

## When to use

Use it after `import math` (or `from math import pi, e`) whenever a calculation needs more than the basic arithmetic operators. The lecture also shows `math.fsum`, which sums ten copies of `0.1` to exactly `1.0` where plain `sum` does not.

See [[Lec_11-Modules and the Standard Library|Lec 11]].
