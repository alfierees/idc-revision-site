Pip is the package installer, the most popular one and shipped with modern Python. It finds, downloads and installs packages from PyPI and other indexes, for packages that are not in the [[Python Standard Library]].

## When to use

Use it for third-party packages such as [[NumPy]], SciPy and matplotlib (`pip install numpy`) before running code that imports them. The slide warns that installation trouble is common, for example a wrong Python environment or a missing install.
