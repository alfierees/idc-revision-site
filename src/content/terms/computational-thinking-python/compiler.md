A program that translates the whole source into [[Machine Code]] before it runs. An [[Interpreter]] instead translates and executes line by line.

## When to use

Lecture 1 sorts languages into the two groups: compiled ones include C, C++, Fortran, Haskell and Pascal, while Python is interpreted. Being interpreted is why you can type one line at the `>>>` prompt and see the result at once.
