NumPy is a package for scientific computing with a powerful N-dimensional array object, conventionally imported as `np`. It is not in the [[Python Standard Library]], so it has to be installed first with [[Pip]].

## When to use

Its arrays behave differently from lists: `+` works element-wise (lists concatenate), `.dot` is the matrix product, and a float anywhere in the input makes the whole array floats. Run `pip install numpy` before code that imports it.
