Teaching computers to learn patterns from data, often to make decisions or predictions. The lecture groups it into supervised learning (classification, regression), unsupervised learning (clustering, dimensionality reduction) and reinforcement learning.

## When to use

It is a field in [[Artificial Intelligence]] and the base that [[Deep Learning]] and [[Generative AI]] build on; it is also one of the ingredients of [[Data Science]].
