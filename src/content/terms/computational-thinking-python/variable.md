A name that refers to a value, created by an assignment statement such as `n = 17`. Names cannot start with a digit, lower case with underscores is the convention (`student_age`), and a variable can later refer to a value of a different type.

## When to use

`n = n + 1` is not a false equation: it evaluates the right side with the current `n`, then rebinds `n`. A variable assigned from another does not track it, so changing `n` later does not change `m`.
