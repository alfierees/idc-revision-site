The program runs fine but gives a wrong result, with no error message (for example a wrong formula or condition). It is the hardest kind of error, since you must review the relevant code yourself.

## When to use

Be able to separate the three kinds: [[Syntax Error]] (caught before running), [[Exception]] (runtime) and logic error. The lecture says an [[Infinite Loop]] is usually a logic error.
