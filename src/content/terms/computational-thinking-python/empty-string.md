The [[String]] `""` with no characters, so `len("")` is `0`. It is smaller than any non-empty string (`"0" > ""` is `True`) and it is in every string.

## When to use

Multiplying a string by `0` or a negative integer gives the empty string rather than an error, and a comprehension should guard against it before indexing `[0]`.

See [[Lec_02-Numeric Values and Strings|Lec 02]].
