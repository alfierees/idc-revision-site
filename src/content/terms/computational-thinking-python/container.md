An object that holds inner elements, classified by whether it is ordered and whether it is mutable. [[List]]s are mutable and ordered, `str` and [[Tuple]] are immutable and ordered, and [[Set]] and [[Dictionary]] are mutable and unordered.

## When to use

Lecture 7 uses this two-way table to place sets and dictionaries next to the containers already met. A list comprehension is not itself a container: it is an expression that builds one.

See [[Lec_07-Dictionaries and Sets|Lec 07]].
