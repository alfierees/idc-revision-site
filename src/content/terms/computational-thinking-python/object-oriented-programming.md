Object-oriented programming models a program as [[Object|objects]] that have their own [[Attribute|attributes]] (state) and [[Method|methods]] (functions performed on the object). Python supports the style, though not to the standards of OOP purists.

## When to use

Objects talk to each other only through well-defined method interfaces, which supports modularity: different teams can build their own object. Lecture 9 introduces it by defining your own types with the `class` keyword, bundling data and code together.

See [[Lec_09-Classes|Lec 09]].
