Access to an element of a [[List]] by its position with `L[i]`, or `L[a][b]` for a [[Nested List]]. Indices start at **0**, and `-1` is the last element.

## When to use

Typical errors are starting a loop at 1 or using `<=` against `len`, since the last valid index is `len - 1`. See [[Slicing]] for ranges of positions.

See [[Lec_04-Lists, For Loops and Ranges|Lec 04]].
