A whole number (`int`). Python 3 integers have **no fixed upper limit** and grow as large as memory allows (`2 ** 100` prints exactly).

## When to use

Integer [[Literal]]s can be written `2000`, `-2000` or `2_000`; a comma is not a separator (`2,000` is the pair `(2, 0)`) and a leading zero such as `02000` is a syntax error. Contrast with the limited range of a [[Float]].
