Pseudo code is a plain-language outline of a solution, with plain-language steps rather than real syntax, written before the real code.

## When to use

It is the second of the three problem-solving steps: define the problem (input and output), formulate the solution (possibly as pseudo code), then implement it in Python. For the temperature converter: get the input temperature C, compute F as 9/5 times C plus 32, output F.
