The intermediate form that Java compiles to before it is interpreted.

## When to use

It appears in the Lecture 1 comparison of translation styles: Python is interpreted line by line, C and C++ are compiled whole by a [[Compiler]], and Java is compiled to bytecode which is then run by an [[Interpreter]].

See [[Lec_01-Hello World|Lec 01]].
