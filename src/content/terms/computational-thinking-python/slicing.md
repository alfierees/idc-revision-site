Taking or assigning a range of a list with `L[a:b]`. Assigning to a slice replaces that stretch of the list, and the replacement can be a different length, so the list can grow or shrink; assigning an empty list deletes the slice.

## When to use

Used to take part of a list, and in exam code such as `lst[i:i+3]` in PP 04 (Q2b). For text the same idea is covered under String Slicing.

See [[Lec_04-Lists, For Loops and Ranges|Lec 04]].
