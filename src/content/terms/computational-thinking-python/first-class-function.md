In Python a [[Function]] is a value like any other: you can put it in a list, assign it to a variable, pass it as an argument or return it from another function.

## When to use

This is what makes `apply`, [[Map and Filter]] work, and it is why a [[Lambda Expression]] can be passed straight to another function.
