Open source is software code freely available to the public that anyone can use, modify and redistribute. Licence terms still bind the user, and copyleft licences (for example GPL) can force you to release your own code as open source if you distribute software incorporating it.

## When to use

It is the fifth of the lecture's core founder risks (improper open-source use): cite it when a startup's proprietary code depends on open-source components and could lose control of its core IP.
