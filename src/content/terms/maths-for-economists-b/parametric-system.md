A linear system containing a letter; ask for which values of the letter the number of solutions changes.

## When to use

A standard exam question: eliminate, then for each parameter value read the verdict (unique, none or infinitely many solutions) from the last rows, using a [[Parameter Case Split]].

See [[Lec_12-Systems with Parameters|Lec 12]].
