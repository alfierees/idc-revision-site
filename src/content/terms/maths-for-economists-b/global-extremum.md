The highest (global maximum) or lowest (global minimum) value of $f$ over the whole domain under consideration, as opposed to a local extremum, which is only the best value nearby.

## When to use

The domain matters: the same formula can have a global maximum on one domain and none on another. Find the [[Critical Point]]s, compare with the values or limits at the ends of the domain, and note that a value only approached cannot be a global extremum.
