Solve a linear system one variable at a time: pivot the variable's coefficient to 1, cancel it from every other row, then move to the next variable and next equation.

## When to use

Use it on any linear system, working on the [[Augmented Matrix]] with [[Elementary Row Operations]]. Stop when the matrix is in [[Reduced Echelon Form]], then read off the solution, as in the $3\times3$ example that gives $(x,y,z) = (2,-1,4)$.

See [[Lec_10-Linear Systems and Gauss-Jordan Elimination|Lec 10]].
