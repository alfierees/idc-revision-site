A function written in separate pieces, such as an absolute value defined by $|x|=x$ for $x\ge0$ and $-x$ for $x<0$; check each piece and the join points.

## When to use

In extrema questions such as those in [[PS_01-Global Extrema and Optimisation|PS 01]], rewrite the function piece by piece, find the extremum of each piece and compare values at the join points.

See [[PS_01-Global Extrema and Optimisation|PS 01]].
