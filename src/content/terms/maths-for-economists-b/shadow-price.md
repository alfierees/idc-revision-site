The rate at which the optimal value changes per unit relaxation of the constraint; it equals $\lambda$.

## When to use

In a Lagrange problem with $\mathcal L=f-\lambda(g-k)$, raising $k$ by one unit changes the optimal value by about $\lambda$, used for approximation questions as in [[PS_09-Lagrange Multipliers|PS 09]].

See [[PS_09-Lagrange Multipliers|PS 09]].
