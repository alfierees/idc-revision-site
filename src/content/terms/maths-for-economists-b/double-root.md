A quadratic whose discriminant is zero, so it touches the axis at one point.

## When to use

In a 2023 Moed B level-curve question, the quadratic for $y$ at $x=0$ has a double root, so the curve passes through exactly one $y$ there. The vault note reads this as the leftmost point of the curve, where $dx/dy = 0$, and flags that reading as its own, consistent with the answer key.
