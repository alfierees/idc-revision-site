Reduce the system without dividing by the parameter, then treat each value that makes a pivot zero as its own case.

## When to use

In a [[Parametric System]], the special parameter values are exactly where the answer changes: dividing a row by the parameter without checking for zero loses a case.

See [[PS_12-Systems with Parameters|PS 12]].
