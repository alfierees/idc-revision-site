The solution with every variable equal to 0, which every [[Homogeneous System]] has.

## When to use

In a homogeneous system the zero solution always exists, so the question is whether other solutions exist: with more unknowns than equations there are free variables, hence infinitely many.

See [[Lec_11-Reduced Echelon Form and Homogeneous Systems|Lec 11]].
