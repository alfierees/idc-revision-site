A linear system stored as a matrix: the coefficients sit to the left of a bar and the constants form an extra column to the right. Each row is one equation and each column is one variable.

## When to use

Write any system as an augmented matrix before reducing it, then apply [[Elementary Row Operations]] and [[Gauss-Jordan Elimination]] until it reaches [[Reduced Echelon Form]].

See [[Lec_10-Linear Systems and Gauss-Jordan Elimination|Lec 10]].
