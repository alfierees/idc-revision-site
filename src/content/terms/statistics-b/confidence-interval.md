A confidence interval is a range built from a sample that is estimated to contain a parameter with a stated confidence: estimate $\pm$ critical value $\times$ [[Standard Error]]. With confidence level $1-\alpha$, $\alpha/2$ sits in each tail.

## When to use

Build it from the matching hypothesis test, taking the standard error and critical value from that test (for example $\bar X \pm t^{1-\alpha/2}_{n-1}\,S_x/\sqrt{n}$). Say "with 95% confidence", never "with probability 95%", because each interval either contains $\mu$ or not.
