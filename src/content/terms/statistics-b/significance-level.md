The predefined probability $\alpha$ below which a result is considered unlikely enough that we reject H0. It is chosen before looking at the data; 0.05 and 0.01 are common in the social sciences.

## When to use

Compare the [[P-Value]] with it (reject if the p-value is below $\alpha$), or use it to set the [[Critical Value]]: one-tailed tests use $\alpha$, two-tailed tests use $\alpha/2$ in each tail. It is also the probability of a [[Type I Error]], and a stricter $\alpha$ lowers [[Statistical Power]].
