The critical value is the cut-off on the test statistic's distribution under $H_0$ with area $\alpha$ beyond it. It marks the edge of the [[Critical Region]].

## When to use

Look it up in the Z, t, chi-squared or F table when working by hand (for $\alpha=0.05$ the Z values are $1.65$, $-1.65$ and $\pm 1.96$). The same value, with the standard error, builds the matching [[Confidence Interval]].

See [[Lec_05-Z Tests, t Tests and Two-Sample Tests|Lec 05]].
