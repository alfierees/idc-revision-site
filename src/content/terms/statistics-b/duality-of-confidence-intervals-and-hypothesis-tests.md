A confidence interval is the set of null values $\mu_{H_0}$ that would not be rejected by the matching test at the same $\alpha$. Both use the same sampling distribution and the same distance condition.

## When to use

If $\mu_{H_0}$ lies inside the interval, do not reject; if outside, reject. This holds only for two-tailed ([[Non-Directional Hypothesis]]) tests.
