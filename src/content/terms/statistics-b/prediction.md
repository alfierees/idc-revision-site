Estimating the value of a single observation, as opposed to a parameter, based on the value (or estimated value) of one or more parameters. With one variable the expected value is the prediction, for example 3.5 for a six-sided die.

## When to use

With a joint distribution, information about one variable improves the prediction of the other only if the variables are not independent, using the [[Conditional Expected Value]] $E(Y \mid X=k)$. Because that needs a large sample, the practical route is a formula: the [[Linear Regression]] line.

See [[Lec_11-Joint Distributions, Correlation and Linear Regression|Lec 11]].
