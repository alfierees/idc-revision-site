The check that the normal approximation is valid for a proportion: the number of successes and the number of failures must both be at least 5, that is $n\hat p \ge 5$ and $n(1-\hat p) \ge 5$.

## When to use

It is step 1 of every proportion test. The single-sample test checks it with the hypothesised $p_{H_0}$, while the two-sample test checks each sample's own $\hat p$; in the ad example the counts 18, 982, 21 and 679 all pass.
