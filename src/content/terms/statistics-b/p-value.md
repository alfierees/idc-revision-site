The probability, given H0, of the observed statistic or one more extreme; doubled for a two-tailed test. It is the main result reported in scientific research.

## When to use

Reject H0 if $p<\alpha$. Take the tail that matches H1: in Terry's sprinters example H1 is $\mu<13$, so the right probability is the lower tail, $P(Z\le-1.83)=0.0336<0.05$ (not $0.9664$).

See [[Lec_04-Hypothesis Testing and the Z Test|Lec 04]]. Also in [[Lec_05-Z Tests, t Tests and Two-Sample Tests|Lec 05]].
