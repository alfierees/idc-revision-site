The hypergeometric distribution models sampling without replacement: $P(X=k)=\binom{D}{k}\binom{N-D}{n-k}/\binom{N}{n}$, where each draw changes the group.

## When to use

It appeared in Problem Set 3 as the without-replacement version of a draw problem: use it to write the likelihood $L(D,x)$ and fill a [[Likelihood Table]], contrasting with the [[Binomial Distribution]] used when draws are with replacement.

See [[PS_03-Maximum Likelihood Estimators|PS 03]].
