A value filter that keeps only the top or bottom N items of a pivot field by a chosen value field, for example the top 3 salespeople by Sum of Total_Income. Despite the name you can pick Top or Bottom and Items, Percent or Sum.

## When to use

It is applied after the other filters, so it ranks only what remains. It decides which items appear but not their display order, so sort by the value field if you need a ranking.
