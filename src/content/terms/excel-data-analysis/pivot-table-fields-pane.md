The panel where fields are dragged into the four areas of a [[Pivot Table]]: Rows (one row per distinct value), Columns (one column per distinct value), Values (the number computed) and Filters (which source rows are used).

## When to use

Put fields with few distinct values in Columns and fields with many in Rows. A numeric field dropped in Values defaults to Sum, a text field to Count.

See [[Lec_07-Pivot Tables|Lec 07]].
