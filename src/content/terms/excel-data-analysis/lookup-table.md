A small reference table that a lookup reads, such as the `Branches` sheet mapping each branch to an area, or the salary bands mapping a lower limit to a bonus.

## When to use

Storing the mapping once means changing one cell updates all 200 rows. Lock the table with [[Absolute Reference]] so it stays put while the lookup value moves down.

See [[Lec_06-Lookups with XLOOKUP and INDEX MATCH|Lec 06]].
