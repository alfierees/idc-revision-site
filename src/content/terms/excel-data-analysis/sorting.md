Reorders whole rows by one or more keys (Data > Sort), including by cell colour or font colour. A multi-level sort applies the levels in the order listed, with later levels breaking ties.

## When to use

Select a cell inside the table so whole records move, because sorting one column alone scrambles the data. Excel puts only one colour on top per level, so ranking red, yellow, then green takes one level per colour.
