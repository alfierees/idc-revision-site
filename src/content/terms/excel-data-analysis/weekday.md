Returns the day of the week as a number; the return type picks the scheme (1 = Sunday first, 2 = Monday first). It returns a number, not a name. Also in [[Lec_04-Date Functions, Named Ranges & Data Validation|Lec 04]].

## When to use

With the default, 15 December 2024 gives 1 because it was a Sunday. To show a name, look the number up in a small table, or format a copy of the date with the custom format `dddd`.

See [[Lec_03-Calendars & Date Calculations|Lec 03]].
