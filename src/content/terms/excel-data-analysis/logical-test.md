An expression Excel answers with TRUE or FALSE, usually a comparison such as `J2>10000` using `=`, `>`, `<`, `>=`, `<=` or `<>`.

## When to use

It is the first argument of an [[IF Function]]. A "between two values" test needs two comparisons joined by an [[AND Function]], because there is no single between operator in a formula.

See [[Lec_02-IF Statements & Logical Functions|Lec 02]].
