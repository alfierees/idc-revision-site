A logical function that is TRUE only when all of its tests are true, and FALSE when one or more are false. On its own it returns TRUE or FALSE, so it is normally wrapped in an [[IF Function]].

## When to use

Use `IF` with `AND` when several conditions must all hold, and use `AND` of a `>=` test and a `<=` test for "between two values". It can also contain an [[OR Function]], as in "name is Gadi, Danny or Hanney, and salary above average".

See [[Lec_02-IF Statements & Logical Functions|Lec 02]].
