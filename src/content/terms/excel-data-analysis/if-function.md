Asks one yes/no question, written `=IF(logical_test, value_if_true, value_if_false)`, and returns one value if the [[Logical Test]] is TRUE and another if it is FALSE. The returned value can be a number, text in quotes, a cell, a calculation or another function.

## When to use

Used for the bonus rule, Senior or Junior labels and similar row-by-row decisions, with the thresholds put in cells and locked with [[Absolute Reference]]. Spot-check several rows after filling down, because a formula can disagree with its written rule.
