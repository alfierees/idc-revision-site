A `.xlsm` or `.xlsb` file that can keep macros; a plain `.xlsx` silently drops them.

## When to use

Save the workbook in one of these formats before closing, or the [[VBA Macro]] code is lost. The class file is `Macro coding.xlsb`.

See [[Lec_08-VBA Macros|Lec 08]].
