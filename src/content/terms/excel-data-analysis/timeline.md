A visual date slider filter for pivots (PivotTable Analyze > Insert Timeline) that works on a real date field and offers Years, Quarters, Months and Days levels.

## When to use

It works only on real dates, not text. Like a [[Slicer]], it only controls pivots connected through [[Report Connections]], which is the trap flagged in the class note.

See [[Lec_07-Pivot Tables|Lec 07]].
