A named block of Visual Basic for Applications code, written `Sub name()` ... `End Sub`, stored in a module inside the workbook. Macro names cannot contain spaces, and the VBA editor opens with Alt+F11.

## When to use

Use a macro for a repetitive task or to give a colleague a [[Macro Button]]. It can only be saved in a [[Macro-Enabled Workbook]] (`.xlsm` or `.xlsb`), and Excel blocks macros from internet files by default.

See [[Lec_08-VBA Macros|Lec 08]].
