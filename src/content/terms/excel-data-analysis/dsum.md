A [[Database Function]] that adds up a field over the records that match the criteria, as in `=DSUM(A1:J201,J1,_xlnm.Criteria)`.

## When to use

In the class example it gave 252495, the same as the sum of the 22 salaries in the [[Advanced Filter]] output. The criteria argument is best written as an ordinary [[Criteria Range]] address.

See [[Lec_01-Sorting, Filters & Database Functions|Lec 01]].
