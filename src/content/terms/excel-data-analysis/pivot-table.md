A report that groups a flat list by row and column fields and aggregates values without writing formulas. Think of it as grouping by the Rows and Columns, then applying a summary function to Values. Also in [[Lec_06-Lookups with XLOOKUP and INDEX MATCH|Lec 06]].

## When to use

The source must be a clean flat list with one unique header per column, no blank rows and real dates. A pivot reads a cached snapshot, so press Refresh after editing the data; and when a pivot total looks too small, check its filters and timeline.

See [[Lec_07-Pivot Tables|Lec 07]].
