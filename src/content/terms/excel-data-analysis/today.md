Returns the current date, recalculated each time the workbook opens or recalculates. It takes no arguments but needs the brackets. Also in [[Lec_04-Date Functions, Named Ranges & Data Validation|Lec 04]].

## When to use

Because it is volatile, results change every day and a saved file shows the values from its last calculation. Freeze a date by typing it or using [[DATE]], and use it inside [[DATEDIF]] to measure time left to a date.

See [[Lec_03-Calendars & Date Calculations|Lec 03]].
