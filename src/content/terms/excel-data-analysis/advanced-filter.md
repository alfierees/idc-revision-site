A filter driven by a [[Criteria Range]] that you build on the sheet in advance (Data > Advanced). It can filter the list in place or copy the matching rows, with only the columns you chose, to another location.

## When to use

Use it when [[AutoFilter]] is not enough, for example OR across different columns or an extract to a new block. Criteria rows multiply quickly, which is why the newer [[FILTER]] function is often more convenient.

See [[Lec_01-Sorting, Filters & Database Functions|Lec 01]].
