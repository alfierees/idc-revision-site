A checkbox list of the pivots built on the same pivot cache, which a [[Slicer]] or [[Timeline]] controls. It is opened from the right-click menu or from PivotTable Analyze > Filter Connections.

## When to use

A new pivot is not connected to an existing slicer or timeline automatically, even on the same sheet, so tick it here. Pivots built from a different source or a separate cache do not appear in the list.

See [[Lec_07-Pivot Tables|Lec 07]].
