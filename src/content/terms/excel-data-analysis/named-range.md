A label for a cell or range, set by selecting it, clicking the Name Box next to the formula bar and typing the name. Formulas can then use the name instead of the address, and a name always points to the same cells, so there is no copying issue.

## When to use

In class, `MyDate` named one cell and `WeekDays` named the 7 by 2 table of day numbers and day names, used in a lookup that turns a weekday number into a day name. Names cannot contain spaces or look like a cell address, so use a form like `WeekDays`.

See [[Lec_04-Date Functions, Named Ranges & Data Validation|Lec 04]].
