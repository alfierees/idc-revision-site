A [[Database Function]] that counts the numeric cells of a field in the records that match the criteria, as in `=DCOUNT(A1:J201,A1,AC242:AD245)`.

## When to use

In the class example it returned 33, the employees in Safed, Karmiel or Raanana whose last name is not Guri. The field must be a column of numbers (Employee ID counts records); for a text column use `DCOUNTA`.

See [[Lec_01-Sorting, Filters & Database Functions|Lec 01]].
