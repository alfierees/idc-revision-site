A shape or button on the sheet with a macro assigned to it, so users run the macro without opening the code.

## When to use

The class workbook has five buttons (Series, Erase, My data, Calculator, BMI), each running one macro. The recorder exercise asks you to add a button to activate the macro.

See [[Lec_08-VBA Macros|Lec 08]].
