Returns the current date and time, recalculated like [[TODAY]]. It takes no arguments but needs the brackets, and the stored value has a whole-number date part and a fractional time part.

## When to use

Because it is volatile, a report using `NOW` changes whenever the workbook is reopened or recalculated. Use [[TODAY]] when you only need the date.

See [[Lec_04-Date Functions, Named Ranges & Data Validation|Lec 04]].
