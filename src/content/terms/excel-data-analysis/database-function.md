The D-functions, which calculate a statistic over only the records that match a [[Criteria Range]]. They all take three arguments: the database (the whole table including the header row), the field (which column) and the criteria range.

## When to use

Use them to get one number for a set of criteria, such as [[DSUM]], [[DAVERAGE]] and [[DCOUNT]] over the employee table, and they update automatically. Criteria headers must match the data headers exactly, and text criteria mean "begins with".

See [[Lec_01-Sorting, Filters & Database Functions|Lec 01]].
