A chart bound to a [[Pivot Table]] that redraws when the pivot changes, whether by a filter, a [[Slicer]], a [[Timeline]] or dragging a field. Some chart types, such as scatter, cannot be used on a pivot chart.

## When to use

In the course workbook, each pivot chart is a clustered-column chart tied to one pivot. Refresh the pivot after changing the source data, because the chart only follows the pivot.

See [[Lec_07-Pivot Tables|Lec 07]].
