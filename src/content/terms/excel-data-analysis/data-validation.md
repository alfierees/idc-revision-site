Rules (Data tab > Data Validation) that limit what can be entered in a cell, such as a whole number between limits, a date range or a drop-down list. An input message and an error alert can be switched on. Also in [[Lec_03-Calendars & Date Calculations|Lec 03]].

## When to use

The class used year 2017 to 2025, month 1 to 12, a Yes/No list and dates between 1960 and 2040, and drop-downs for the month and year of the calendar. It only checks what is typed, so pasting a value over the cell or already bad data is not caught.

See [[Lec_04-Date Functions, Named Ranges & Data Validation|Lec 04]].
