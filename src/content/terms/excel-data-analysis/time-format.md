A number format that changes how a time is displayed (`h:mm`, `h:mm AM/PM`, `h:mm:ss` and so on) without changing its value. Set it in Format Cells (Ctrl+1) with a Time category or a custom code.

## When to use

The same cell value, 0.4065..., shows as 9:45 or 9:45:22 AM depending on the format. For totals that can pass 24 hours use [[Elapsed Time Format]] instead, or the display wraps.

See [[Lec_05-Time Functions & Protecting Cells|Lec 05]].
