TRUE when at least one of its tests is true, and FALSE only when all are false. It is written `OR(logical1, logical2)` and is normally used inside an [[IF Function]].

## When to use

Use it when any one of several conditions is enough, for example a name matching any of three values. It can be wrapped around [[AND Function]] blocks, such as accepting a date in either of two ranges.

See [[Lec_02-IF Statements & Logical Functions|Lec 02]].
