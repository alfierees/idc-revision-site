Review > Protect Sheet, which enforces the Locked and Hidden flags; a password is optional. Every cell is locked by default, but that does nothing until sheet protection is switched on, and Review > Unprotect Sheet removes it.

## When to use

Mark the exceptions first: untick Locked on the input cells (Format Cells, Protection tab), then protect the sheet. If you set a password and lose it you cannot edit the sheet, so skip it when you only want to stop accidental overwrites.
