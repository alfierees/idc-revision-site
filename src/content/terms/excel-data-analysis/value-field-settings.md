The dialog to change a value field's summary function (Sum, Average, Count), its custom name and its [[Show Values As]] option. It is reached through Value Field Settings > Summarize Values By.

## When to use

Drag the same field into Values more than once to get several columns, such as a sum, an average and a percentage. The Grand Total of an Average column is the average over all rows, not the average of the averages.

See [[Lec_07-Pivot Tables|Lec 07]].
