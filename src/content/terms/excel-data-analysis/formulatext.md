Shows another cell's formula as text, so `=FORMULATEXT(E5)` prints the formula that lives in `E5`. If the cell holds a constant it returns `#N/A`. Also in [[Lec_05-Time Functions & Protecting Cells|Lec 05]].

## When to use

Used on the date and time function sheets so each label is read from the real formula and cannot drift out of date. It is useful for teaching and for auditing a sheet.

See [[Lec_04-Date Functions, Named Ranges & Data Validation|Lec 04]].
