A VBA statement that shows a pop-up message box. Its arguments are the message, the button style (which can be skipped, giving a double comma) and the window title.

## When to use

The class `mydata_new` macro ends with a MsgBox thank-you message. Remember that text inside the quotation marks is not checked by VBA, so a typo in the message will still run.

See [[Lec_08-VBA Macros|Lec 08]].
