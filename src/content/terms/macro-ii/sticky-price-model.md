A model in which firms set their own prices (monopolistic competition) and a share $s$ must fix them in advance using expected prices, while the rest set $p = P + a(Y-\bar{Y})$. The overall price level then responds only partly to demand, which gives an upward-sloping SRAS.

## When to use

Use it to see the extreme cases: all prices sticky ($s = 1$) gives a horizontal SRAS, all flexible ($s = 0$) gives a vertical LRAS, and the mixed case gives the upward slope.
