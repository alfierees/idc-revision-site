Expected inflation equals last period's inflation, $E\pi = \pi_{-1}$. Substituting this into the Phillips curve gives $\pi = \pi_{-1} - \beta(u - u_n) + \nu$.

## When to use

Use it for disinflation questions: with adaptive expectations the cost of reducing inflation is large because expectations adjust only slowly.
