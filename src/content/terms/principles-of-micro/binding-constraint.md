A price control is binding when it forbids the free-market equilibrium price, so it changes the outcome. It is not binding when the equilibrium price is already legal, so it has no effect.

## When to use

Check which side of the equilibrium price the control sits: a [[Price Ceiling]] binds when it is below equilibrium (giving a [[Shortage]]), a [[Price Floor]] binds when it is above (giving a [[Surplus]]). Otherwise it has no effect (Lec 10, PS 10).

See [[Lec_10-Price Controls|Lec 10]].
