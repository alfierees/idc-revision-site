Computes percentage changes using the average of the start and end values as the base, so the elasticity is the same whichever end is called the start.

## When to use

Use it whenever a question gives two price-quantity points and asks for the [[Price Elasticity of Demand]]: compute both midpoints, both percentage changes, divide, then read the sign and compare the size with 1. The exam formula sheet uses the same notation.

See [[Lec_08-Elasticity|Lec 08]].
