The core Python plotting library (`import matplotlib.pyplot as plt`), which [[Seaborn]] builds on.

## When to use

Use it for the standard charts in EDA: `plt.scatter`, a line plot, `.hist(bins=...)`, and for labelling axes and titles. Add Seaborn for grouped charts such as boxplots and heatmaps.

See [[Lecture 2 - EDA and Charts|DS Lec 2]].
