A statistical plotting library built on [[Matplotlib]], with cleaner defaults for grouped charts.

## When to use

In the lecture's code it supplies `sns.boxplot` for spread across groups and `sns.heatmap` for a correlation matrix, and `sns.set_style("whitegrid")` for the styling. Use it for the standard chart types of exploratory analysis.

See [[Lecture 2 - EDA and Charts|DS Lec 2]].
