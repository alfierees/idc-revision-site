The Python library for tabular data, built around the [[DataFrame]]. It is the toolkit for loading a CSV and inspecting it with commands such as `head()`, `info()`, `describe()` and `groupby()`.

## When to use

Any exploratory question in code starts here: load with `pd.read_csv`, then run `.head()` and `.info()` first on a new dataset (the lecture's non-negotiable first move), then filter, sort and summarise.
