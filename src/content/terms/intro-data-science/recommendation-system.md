An algorithm that predicts how much a user would like an item they have not seen yet and suggests the items with the highest predicted ratings.

## When to use

Frame any recommendation question as filling the blank cells of the [[User-Item Matrix]]. Choose between [[Content-Based Filtering]], [[Collaborative Filtering]] (user-based or item-based) and a [[Hybrid Recommender]], and mention the [[Cold Start Problem]]. It beats a single most-popular list because personalisation reaches the [[Long Tail]].
