A free, cloud-based Jupyter notebook environment that runs Python in the browser with zero installation ("Google Docs for code").

## When to use

Every recitation and assignment is a notebook run in Colab; submit by running all cells and downloading the notebook as .ipynb. Cells must run in order, and the runtime disconnects after about 90 minutes of inactivity.
