The average feature vector of the items a user rated highly (say 4 or above), summarising their taste in feature space.

## When to use

Step 2 of [[Content-Based Filtering]]: describe items with feature vectors, build the profile, compute [[Cosine Similarity]] between the profile and each unseen item, then rank. In the lecture's example User A's profile came out heavy on Drama, Crime, Thriller and Hebrew.

See [[Lecture 6 - Recommendation Systems|DS Lec 6]].
