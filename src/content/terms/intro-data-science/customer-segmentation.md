Using clustering to find natural groups of customers with similar behaviour so each can be targeted differently. The lecture's StyleNation case finds four segments: VIP Loyalists, Bargain Hunters, Window Shoppers and New Enthusiasts.

## When to use

After choosing $K$ with the [[Elbow Method]] and [[Silhouette Score]], profile each cluster with a groupby of feature means, compare with the dataset mean, and give it a descriptive name that suggests an action ("call the VIP Loyalists first").
