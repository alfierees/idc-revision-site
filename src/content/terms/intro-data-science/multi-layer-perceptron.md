A network of fully connected layers: an input layer, one or more [[Hidden Layer]]s and an output layer.

## When to use

The lecture's demo MLP has 3 inputs, 2 hidden neurons and 1 output, which gives 11 parameters. PS 07 builds one with scikit-learn's `MLPClassifier`.
