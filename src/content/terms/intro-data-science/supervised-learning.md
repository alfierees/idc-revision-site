Learning a mapping from features $X$ to a known label $y$ using labelled examples. Classification predicts a discrete label and regression predicts a number.

## When to use

Identify it by the presence of a target column to predict (churn, valuation). The pipeline is data, split, train, predict, evaluate, with a held-out test set to measure honest performance; contrast it with [[Unsupervised Learning]], which has no labels. Appears in [[PS_01-Titanic Classification Basics|PS 01]].
