All the bundles the consumer strictly prefers to a given bundle $x$; it lies above the [[Indifference Curve]] through $x$ and excludes that curve.

## When to use

Use it alongside the [[Weakly Preferred Set]] to describe regions of the preference map: the weak set includes the curve, the strict set does not.

See [[Lec_02-Preferences|Lec 02]].
