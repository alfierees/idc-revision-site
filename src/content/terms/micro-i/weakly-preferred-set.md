All the bundles the consumer likes at least as much as a given bundle $x$; it includes the [[Indifference Curve]] through $x$.

## When to use

Use it alongside the [[Strictly Preferred Set]]: the weak set contains the indifference curve and everything above it, the strict set only what lies above.

See [[Lec_02-Preferences|Lec 02]].
