$P(X=x_i)$ for each value $x_i$ of a discrete random variable; a distribution table is one way of writing it down, and the values sum to 1.

## When to use

Running-total it to build the CDF. For a continuous variable it is useless (every single value has probability 0), so the PDF is used instead.

See [[Lec_05-Random Variables, Expected Value and Variance|Lec 05]].
