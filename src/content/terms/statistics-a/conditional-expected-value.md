$E(X|Y=y_j)$ is the expected value computed with the conditional distribution instead of the ordinary one: it answers what value of $X$ to expect once $Y=y_j$ is known.

## When to use

Use the same recipe as [[Expected Value]] (value times probability, summed), but with the conditional probabilities from a joint table, for example the expected number of heads on two coins given 2 heads in total.

See [[Lec_08-Joint Distributions, Conditional Distributions and Covariance|Lec 08]].
