A collection of elements written in curly brackets, such as $A=\{1,2,3\}$, with size $|A|$ and the empty set $\varnothing$.

## When to use

Events are sets of results, so set language (equality, inclusion, disjointness, union, intersection, complement) is the vocabulary of probability.

See [[Lec_01-Sets and the Probability Function|Lec 01]].
