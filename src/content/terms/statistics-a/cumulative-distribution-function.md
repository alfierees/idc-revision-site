$F(x)=P(X \le x)$: the running total of the PMF, the probability of getting that value or less.

## When to use

Read a CDF table cell for $P(X \le x)$, and watch the inequality: for whole-number values "less than 21" means $\le 20$. For continuous variables it is the basis for percentiles and for the [[Probability Density Function]], $f(x)=F'(x)$.

See [[Lec_05-Random Variables, Expected Value and Variance|Lec 05]].
