The value $C$ with $F(C)=n/100$, below which $n\%$ of the probability lies; also called a quantile $C_a$ when the fraction is $a$.

## When to use

Set the CDF equal to the target probability and invert. For a normal, read the Z table backwards and then un-standardize with $C_q=\mu+\sigma Z$, rewriting "higher than" as "lower than" first.

See [[Lec_10-Continuous Random Variables and the Uniform Distribution|Lec 10]].
