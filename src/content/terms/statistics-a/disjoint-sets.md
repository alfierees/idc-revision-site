Sets with no element in common, $A \cap B = \emptyset$.

## When to use

Additivity ($P(A \cup B)=P(A)+P(B)$) holds only for disjoint events; otherwise subtract $P(A \cap B)$. Disjoint events with positive probabilities are never independent, so test the two properties separately (Moed B 2023, Question 5).
