A random variable is continuous if between any two possible values there is always another possible value, like height, time, temperature or weight in the model.

## When to use

For these variables the table-of-probabilities method fails, so you work with the [[Cumulative Distribution Function]] and the [[Probability Density Function]], where probability is area.

See [[Lec_10-Continuous Random Variables and the Uniform Distribution|Lec 10]].
