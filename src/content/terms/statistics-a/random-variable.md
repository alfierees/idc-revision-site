A variable whose value is set by the result of a random experiment, for example the age of a randomly chosen student. It replaces the event as the framework for uncertainty, since it can take many values.

## When to use

Write it as $X$ with possible values $x_i$ and describe it by its distribution, from which expected value and variance follow.

See [[Lec_05-Random Variables, Expected Value and Variance|Lec 05]].
