$P(A \cup B) = P(A) + P(B) - P(A \cap B)$. For disjoint events the intersection term is 0, so the additivity axiom is a special case.

## When to use

Use it to find an intersection from a union (Moed B 2023, Question 5: $P(A \cap B)=0.2+0.5-0.6=0.1$). Adding $P(A)+P(B)$ for overlapping events double counts the overlap and can exceed 1.
