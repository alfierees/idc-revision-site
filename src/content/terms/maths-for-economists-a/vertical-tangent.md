A point where both one-sided slopes are infinite with the same sign ($+\infty$ on both sides or $-\infty$ on both), so the vertical line through the point is tangent. The function is not differentiable there.

## When to use

Seen at $x=0$ for $\sqrt[5]{x}$. It is a critical point (the derivative is undefined while $f$ is continuous) but not an extremum, because the sign of $f'$ does not change.

See [[Lec_07-The Derivative, Differentiability and Rules|Lec 07]].
