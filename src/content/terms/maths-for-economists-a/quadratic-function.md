A function $f(x)=ax^2+bx+c$ whose graph is a parabola. It opens up if $a>0$ and down if $a<0$, with roots from $ax^2+bx+c=0$.

## When to use

Shows up as revenue and profit in the business questions (for example $R(p)=6000p-30p^2$) and inside an absolute value such as $\lvert x^2+x-6\rvert$.
