Plugging the point into the formula to find a limit. It is valid at points where the function is continuous, so $\lim_{x\to a}f(x)=f(a)$.

## When to use

Always try it first. If it returns a number you are done; if it returns $\frac{0}{0}$, simplify by factoring or using a [[Conjugate]], then substitute again.

See [[Lec_04-Limits and Continuity|Lec 04]].
