The set of $y$ values the function actually produces, with nothing extra added, written $R_{min}$. It is the range of the function, as opposed to a larger set that merely contains all the outputs.

## When to use

Asked alongside the domain when you test whether an equation is a function, for example $R_{min}=(-\infty,-3]$ for $y=-\sqrt{x^2+9}$ or all reals except $1$ for $y=\frac{x}{x-1}$.
