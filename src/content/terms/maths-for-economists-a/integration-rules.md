The sum rule, the constant multiple rule and the linear-inside rule $\int f(ax+b)\,dx=\frac{F(ax+b)}{a}+C$, which is the chain rule run backwards for a linear inside function.

## When to use

Use the third rule only when the inside is linear, for example $\int(4x+1)^5\,dx=\frac{(4x+1)^6}{24}+C$. If the inside is not linear, as in $(1+\sqrt{x})^2$, expand first.
