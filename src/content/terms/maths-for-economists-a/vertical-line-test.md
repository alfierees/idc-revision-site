A graph is the graph of a function exactly when no vertical line meets it in more than one point. If some vertical line hits two points, that $x$ has two $y$ values.

## When to use

The picture version of the algebra check: the line $x=4$ hits both $(4,5)$ and $(4,-5)$ on $y^2-x^2=9$, so that equation is not a function.
