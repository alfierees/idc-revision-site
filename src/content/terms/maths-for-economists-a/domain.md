The set of input values for which the function is defined. Two rules cover almost everything: the denominator cannot be zero, and the expression under a square root cannot be negative.

## When to use

Write the domain first whenever you analyse a function, for example $x\le 16$ for $y=-\sqrt{16-x}$. Excluded points also split the number line in sign tables later.
