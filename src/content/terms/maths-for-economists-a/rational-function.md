A rational function is a fraction of two polynomials, such as $\frac{3x-1}{x-2}$. It is undefined where the denominator is zero, which gives either a [[Vertical Asymptote]] or, if a factor cancels, a [[Removable Discontinuity]].

## When to use

Factor and cancel first, then read off the holes and asymptotes. This is the opening move when investigating a fraction in an exam.

See [[Lec_11-Concavity, Inflection Points and Asymptotes|Lec 11]].
