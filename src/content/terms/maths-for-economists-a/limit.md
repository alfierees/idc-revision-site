The value $f(x)$ approaches as $x$ approaches a point, written $\lim_{x\to a}f(x)=L$, without caring about the value at the point itself. It exists only if the left and right limits both exist and are equal.

## When to use

Ask where the graph is heading, as opposed to where the point actually sits. Compare left limit, right limit and value at seam points, and split absolute values first.
