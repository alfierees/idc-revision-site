An odd root such as a cube root accepts negative inputs, so it adds no restriction to the domain. This is unlike a square root, which needs a non-negative argument.

## When to use

Appears when the domain of $\sqrt[5]{x}$ or $\sqrt[3]{x^2}$ is asked before testing differentiability at $x=0$. Both have domain all real numbers.
