A function $y=a^x$ with $a>0$. It passes through $(0,1)$ because $a^0=1$, grows for $a>1$ and decays for $0<a<1$, with the x axis as a horizontal asymptote.

## When to use

Combine it with shifts to sketch graphs such as $2^{x+3}-5$, and use the limits at infinity (for $a>1$, $a^x\to\infty$ as $x\to\infty$ and $a^x\to 0$ as $x\to-\infty$) when two exponentials compete.

See [[Lec_03-Composition, Transformations, Exponentials and Limits|Lec 03]].
