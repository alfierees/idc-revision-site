How the slope changes. The function is concave up where $f''>0$ (slope increasing, shaped like a cup) and concave down where $f''<0$ (slope decreasing, shaped like a cap).

## When to use

Find $f''$ and build a sign table. Do not treat an excluded domain point as a normal point, since it splits intervals but can never be an inflection point.

See [[Lec_11-Concavity, Inflection Points and Asymptotes|Lec 11]].
