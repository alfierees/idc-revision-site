The function $\lvert g\rvert$, equal to $g$ where $g\ge 0$ and to $-g$ where $g<0$. It is a piecewise function that splits where $g=0$, and its graph is the graph of $g$ with the part below the x axis reflected upward.

## When to use

Rewrite it as a piecewise function using a sign table of the inside, as for $\lvert x^2+x-6\rvert$. Split it first before cancelling or taking one-sided limits.

See [[Lec_02-Piecewise Functions and Business Applications|Lec 02]].
