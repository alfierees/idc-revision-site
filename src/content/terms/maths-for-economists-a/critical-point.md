A point in the domain where $f$ is continuous and $f'$ is $0$ or undefined. It is only a suspect for an extremum.

## When to use

Every relative extremum is a critical point but not every critical point is an extremum, so check whether $f'$ changes sign. Points outside the domain, like $x=0$ for $\frac{1}{x}$, split the line but are never critical points.
