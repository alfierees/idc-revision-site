The original regression with all coefficients free; it always fits at least as well as the restricted model.

## When to use

In an F-test it supplies $RSS_{UR}$, the benchmark against which the restricted model's $RSS_R$ is compared.

See [[Lec_07-Multiple Hypothesis Tests|Lec 7]].
