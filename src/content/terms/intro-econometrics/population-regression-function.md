The true model $y=\beta_0+\beta_1 x+u$ for the whole population, whose parameters are unobserved and which regression tries to estimate. Lecture 1 also calls it the true model or the theoretical model.

## When to use

Use it to state what the parameters mean (for example $\beta_1$ as the causal effect of $x$ on $y$) before estimating them; the estimated counterpart is the sample regression function.
