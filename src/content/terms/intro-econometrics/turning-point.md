The $x$ where a quadratic's slope is zero, $x^*=-\beta_1/(2\beta_2)$ in $y=\beta_0+\beta_1 x+\beta_2 x^2$: a peak if $\beta_2<0$, a trough if $\beta_2>0$.

## When to use

Set the derivative to zero (first-order condition) and solve; use it whenever a quadratic model asks where the effect changes direction.
