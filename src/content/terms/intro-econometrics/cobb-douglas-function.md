A multiplicative cost or production function that becomes linear in its parameters once you take logs, so each slope is an elasticity.

## When to use

In the Lecture 7 cost example, take logs of cost, output and input prices, then read the coefficient on $\ln Y$ as the elasticity of cost with respect to output and test constant returns to scale with a joint test.

See [[Lec_07-Multiple Hypothesis Tests|Lec 7]].
