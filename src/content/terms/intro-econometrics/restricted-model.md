The original regression with the null hypothesis imposed, so it has fewer free coefficients.

## When to use

In a multiple-hypothesis test, build it by substituting the null into the original model, estimate it, and compare its $RSS$ with the unrestricted model in an F-test.

See [[Lec_07-Multiple Hypothesis Tests|Lec 7]].
