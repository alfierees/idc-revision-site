A test that puts all of $\alpha$ in one tail, used when the alternative has a direction ($\beta>b$ or $\beta<b$).

## When to use

Use the same t-statistic but the one-tail critical value $t_\alpha[df]$ (the 1-tailed row of the t-table). Failing to reject both $\beta\ge b$ and $\beta\le b$ is not a contradiction.
