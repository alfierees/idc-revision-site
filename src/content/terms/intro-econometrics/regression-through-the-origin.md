A model with no intercept ($\beta_0=0$), giving $\tilde\beta_1 = \sum x_i y_i/\sum x_i^2$. It coincides with the usual slope only if $\bar x = 0$, and it is unbiased only if the true intercept is genuinely zero.

## When to use

Questions ask when dropping the intercept is legitimate (test whether it is zero first, as in Assignment 3). Neither $R^2$ nor adjusted $R^2$ can compare a no-intercept model with one that has an intercept.
