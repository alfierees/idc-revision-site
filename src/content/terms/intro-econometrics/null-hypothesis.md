The claim $\beta=b$ that a test tries to reject, set against an alternative $H_1$.

## When to use

State it first in the four-step test (hypotheses, t-statistic, critical value, decision); rejecting it means the data are unlikely if it were true, and failing to reject does not prove it.

See [[Lec_06-Hypothesis Tests & p-values|Lec 6]].
