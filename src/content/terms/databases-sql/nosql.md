An umbrella term for database paradigms not based on relational theory, including document, columnar, graph, object and time-series databases.

## When to use

Use it when contrasting relational databases with systems designed for very large internet scale. Taught in [[Lec_13-Indexes, Views & NoSQL|Lecture 13]].
