A client program for writing SQL and sending it to a server; it provides the editor and result viewer but does not run the SQL itself.

## When to use

PP 05 Q4 tests this: with Workbench installed but no [[MySQL Server]] and no connection to one, you cannot run SQL commands.

See [[PP_05-Foreign Key Purpose, WHERE vs HAVING, Optional INSERT Columns, Workbench vs Server & Identifiers vs Keywords (Sample Questions)|PP 05]].
