Data Manipulation Language: SQL that reads or changes rows: [[SELECT]], [[INSERT INTO]], [[UPDATE]] and [[DELETE]]. Contrast [[DDL]], which changes structure.

## When to use

PP 04 Q4.4 classes `DISTINCT` as DML because it is used in SELECT queries, and `UNIQUE` as DDL.
