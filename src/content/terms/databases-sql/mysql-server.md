The program that executes SQL commands and stores the data. MySQL Workbench is only a client that sends commands to it.

## When to use

PP 05 Q4 asks whether Lisa can run SQL with Workbench installed but no server: she cannot, because the server executes the command. She needs a local server or a connection to a remote one.
