A name that belongs to your own database, such as the name of a database, table or column. Identifiers are specific to the database being worked on.

## When to use

PP 05 Q5 asks for the difference between an identifier and a [[Keyword]]: identifiers are names of things in the database, keywords are part of the SQL language itself.

See [[PP_05-Foreign Key Purpose, WHERE vs HAVING, Optional INSERT Columns, Workbench vs Server & Identifiers vs Keywords (Sample Questions)|PP 05]].
