A keyword such as SELECT or DISTINCT that can be used as an identifier only when quoted with backticks.

## When to use

Use backticks for names like `character` or `order`. Without them the statement is a syntax error. Taught in [[Lec_05-Normalization & SQL Syntax|Lecture 5]].
