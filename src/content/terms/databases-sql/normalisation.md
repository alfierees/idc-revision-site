Organising data into tables to reduce redundancy and update anomalies, in steps called normal forms (1NF, 2NF, 3NF).

## When to use

Read 01 covers it in only a few lines, and no past paper or problem set asks for it directly. Use it to recognise when one table repeats data that should live in its own table.
