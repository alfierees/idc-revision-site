The automated process of loading data into a database from outside sources; doing the same thing manually is called importing.

## When to use

Relevant when getting CSV files into MySQL, where encoding, delimiters and data types can all cause failures. Taught in [[Lec_11-Nested Subqueries, INSERT, UPDATE & DELETE|Lecture 11]].
