The way a relational database stores data: each [[Entity]] becomes a table, each [[Attribute]] a column, and each [[Tuple]] a row, with tables linked by [[Relationship|relationships]] whose [[Cardinality]] says how many rows on one side match the other.

## When to use

It is the vocabulary behind every ERD-to-tables question in the past papers (for example PP 03 Q1). Strictly, an entity becomes a table only once the ERD is translated into a logical schema.
