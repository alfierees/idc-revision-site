A function that returns 1 for rollup rows and 0 for regular rows.

## When to use

Use it with WITH ROLLUP to tell sub-total rows apart from real rows that contain NULL. Taught in [[Lec_12-WITH ROLLUP, CTEs & Indexes|Lecture 12]].
