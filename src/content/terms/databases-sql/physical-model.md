The ER model as implemented in one specific product, with data types, constraints, indexes and storage details.

## When to use

Use it to tell the three model levels apart: anything vendor-specific, such as a MySQL Workbench EER diagram, is physical. Taught in [[Lec_02-Conceptual Entity-Relationship Modeling|Lecture 2]].
