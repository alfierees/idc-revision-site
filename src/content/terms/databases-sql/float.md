A 32-bit floating-point type that stores approximate values; DOUBLE is the 64-bit version.

## When to use

Use it only for very large or very small numbers. It explains results like 2.33999999999 instead of 2.34. Taught in [[Lec_08-Constraints & Data Types|Lecture 8]].
