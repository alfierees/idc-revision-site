A client sends requests and a server executes them and returns results. [[MySQL Workbench]] is only the client; the SQL is run and the data held by [[MySQL Server]].

## When to use

PP 05 Q4: a student with Workbench installed but no server cannot run SQL, so she must install a server or get a connection to one.
