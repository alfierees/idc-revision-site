An exact fixed-point number type declared as DECIMAL(precision, scale).

## When to use

Use it for money and other values that must be exact. DECIMAL(5,2) ranges from -999.99 to 999.99. Taught in [[Lec_08-Constraints & Data Types|Lecture 8]].
