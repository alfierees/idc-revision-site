The column, or combination of columns, that uniquely identifies each row. It is unique and never NULL, and a table has one primary key definition.

## When to use

Tested when turning an ERD into tables (PP 03) and when choosing a key for a many-to-many table: PP 04 Q6 compares a [[Composite Primary Key]] with a [[Surrogate Key]]. The study guide adds that a primary key can be composite.

See [[PP_03-ERD to Tables, JOIN Counts, Foreign Key Mechanisms, GROUP BY & INSERT Defaults (2024 Moed A)|PP 03]].
