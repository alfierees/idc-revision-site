Data Definition Language: SQL that defines or changes structure (tables, views, indexes) rather than rows: CREATE, ALTER, DROP and TRUNCATE.

## When to use

PP 04 Q4.4 uses the split: `UNIQUE` is a DDL feature in CREATE or ALTER TABLE, while `DISTINCT` is DML in a SELECT. Contrast [[DML]].
