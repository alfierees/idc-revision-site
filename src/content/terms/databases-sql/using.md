A shortcut for ON when the joined column has the same name in both tables; the column then appears once in the result.

## When to use

Use it for joins like JOIN capital USING (country_id). It cannot be used when the PK and FK names differ. Taught in [[Lec_11-Nested Subqueries, INSERT, UPDATE & DELETE|Lecture 11]].
