Deletes a table together with its data permanently, structure included. Contrast [[DELETE]], which removes rows only, and [[TRUNCATE TABLE]], which keeps the structure.

```sql
DROP TABLE customer;
```

## When to use

The reading's exam tip: DELETE removes data, DROP removes structure. No past-paper question tests it directly.

See [[Read_01-SQL Keywords, Concepts & Exam Tips|Read 01]].
