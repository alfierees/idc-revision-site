A common table expression joined with itself, built from a base case and a recursive step combined with UNION ALL.

## When to use

Use it to walk hierarchies, such as computing each employee's rank in an organisation. Taught in [[Lec_12-WITH ROLLUP, CTEs & Indexes|Lecture 12]].
