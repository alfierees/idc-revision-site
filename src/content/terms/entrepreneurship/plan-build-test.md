The three-step prototyping loop: decide what to learn (Plan), build a low-fidelity model of the critical feature (Build), test with real users and refine (Test).

## When to use

Use this in the second diamond, when building, testing and refining a solution with users. Covered in [[Lec_11-Practical Innovation 3|Lec 11]].
