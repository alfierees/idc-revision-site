UK Design Council process model: problem diamond (Discover → Define) + solution diamond (Develop → Deliver), each alternating divergent and convergent thinking.

## When to use

Use this when structuring a user-centered innovation process or testing whether a solution is worth pursuing. Covered in [[Lec_09-Practical Innovation 1|Lec 09]].
