The value-added approach measures GDP as the sum of every firm's value added plus government value added. A firm's value added is sales plus the change in inventory minus purchases from other firms, so intermediate goods are not double-counted.

## When to use

Build each firm's value-added column from its profit-and-loss table, subtract [[Depreciation]] for net value added, and add government value added (wages plus rent). It must equal the income and expenditure results, so use it as a cross-check.

See [[Rec_02-The Three Approaches to Measuring GDP|Rec 02]].
