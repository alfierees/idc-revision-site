Returns to scale describe how output responds when all inputs are scaled by the same factor $t$: if output scales by $t^k$, returns are increasing for $k > 1$, constant for $k = 1$ and decreasing for $k < 1$. For Cobb-Douglas, $k$ is the sum of the exponents. Seen in: [Macro-Economics](/subjects/macro-economics).

## When to use

Scale every input by $t$ and read the power of $t$, which is the sum of exponents. Cobb-Douglas $Y = AK^{\alpha}L^{1-\alpha}$ has constant returns for every $0 < \alpha < 1$.
