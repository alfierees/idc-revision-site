The probability-weighted average of an asset's possible returns; for a portfolio it is the weighted average of the assets' expected returns, $w_1E[R_1]+w_2E[R_2]$. Unlike risk, it has no correlation cross term.

## When to use

Use it in two-asset and three-asset portfolio questions, with weights that add to 1 (negative for a leveraged or short-sold position). With historical data, use the plain average.
