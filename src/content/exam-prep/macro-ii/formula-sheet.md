## Classical model and money

| Quantity | Formula |
|---|---|
| Output | $\bar Y = F(\bar K, \bar L)$ |
| Factor prices | $W/P = MPL$, $R/P = MPK$ |
| Euler (constant returns) | $Y = MPL\cdot L + MPK\cdot K$ |
| Cobb-Douglas shares | $Y = AK^\alpha L^{1-\alpha}$: capital $\alpha$, labour $1 - \alpha$ |
| National saving | $S = Y - C(Y - T) - G$ |
| Goods market | $S = I(r)$ |
| Quantity equation | $MV = PY$ |
| Inflation | $\pi = \%\Delta M + \%\Delta V - \%\Delta Y$ |
| Fisher | $i = r + E\pi$ (ex post $r = i - \pi$) |
| Money demand | $M/P = L(i, Y)$, often $kY$ or $aY - bi$ |
| Money multiplier | $M = mB$, $m = \dfrac{1 + cr}{cr + rr}$ |
| Bank capital | assets − liabilities (deposits + debt) |

## Solow

| Quantity | Formula |
|---|---|
| Capital accumulation | $\Delta k = sf(k) - (\delta + n + g)k$ |
| Steady state | $sf(k^*) = (\delta + n + g)k^*$ |
| Saving rate from data | $s = (\delta + n + g)\,K/Y$ |
| Cobb-Douglas steady state ($y = k^\alpha$) | $k^* = \left(\dfrac{s}{\delta + n + g}\right)^{1/(1-\alpha)}$ |
| Consumption per worker | $c^* = (1 - s)f(k^*) = f(k^*) - (\delta + n + g)k^*$ |
| Golden rule | $MPK = \delta + n + g$; Cobb-Douglas: $s_{gold} = \alpha$ |
| AK model | $\Delta K/K = sA - \delta$ (growth forever if $sA > \delta$) |

| Steady-state growth rates | |
|---|---|
| $k$, $y$ (per effective worker), $MPK$, $K/Y$, factor shares | 0 |
| $K/L$, $Y/L$, real wage | $g$ |
| $K$, $Y$ | $n + g$ |

## Short run

| Quantity | Formula |
|---|---|
| Keynesian cross | $Y = C(Y - T) + I + G$ |
| Spending multiplier | $1/(1 - MPC)$ |
| Tax multiplier | $-MPC/(1 - MPC)$ |
| Balanced-budget multiplier | 1 |
| IS | $Y = C(Y - T) + I(r) + G$ |
| LM | $M/P = L(r, Y)$ |
| Linear IS with $C = c_0 + c(Y - T)$, $I = i_0 - dr$ | $Y = \dfrac{c_0 - cT + i_0 + G - dr}{1 - c}$ |
| Crowding out of investment | $\Delta I = \Delta Y_{IS\text{-}LM}(1 - MPC) - \Delta G$ |

| Closed-economy IS-LM shock | Shift | $Y$ | $r$ |
|---|---|---|---|
| $G\uparrow$, $T\downarrow$, optimism | IS right | ↑ | ↑ |
| $M\uparrow$, $P\downarrow$, money demand ↓ | LM right | ↑ | ↓ |

## Mundell-Fleming ($r = r^*$, $e$ up = appreciation)

| Quantity | Formula |
|---|---|
| IS* | $Y = C(Y - T) + I(r^*) + G + NX(e)$ |
| LM* | $M/P = L(r^*, Y)$ (vertical) |
| Real exchange rate | $\varepsilon = e\cdot P/P^*$ |
| Risk premium | $r = r^* + \theta$ |

| Shock | Floating: $Y$ / $e$ | Fixed: $Y$ / $M$ |
|---|---|---|
| $G\uparrow$ or $T\downarrow$ | 0 / ↑ | ↑ / ↑ |
| $M\uparrow$ | ↑ / ↓ | 0 / back to start |
| Import quota | 0 / ↑ ($NX$ unchanged) | ↑ / ↑ ($NX$ up) |
| $\theta\uparrow$ | ↑ / ↓ (in the model) | ↓ / ↓ (CB cuts $M$) |

## Aggregate supply and the Phillips curve

| Quantity | Formula |
|---|---|
| SRAS | $Y = \bar Y + \alpha(P - EP)$ |
| Sticky-price slope | $\alpha = \dfrac{s}{(1 - s)a}$ ($s$ = share of sticky firms) |
| Phillips curve | $\pi = E\pi - \beta(u - u^n) + \nu$ |
| Adaptive expectations | $E\pi = \pi_{-1}$ |
| Cyclical unemployment to cut $\pi$ by $x$ | $u - u^n = x/\beta$ (one period) |
| Okun's law | $\%\Delta Y \approx -2\,\Delta u$ |
| Sacrifice ratio | % of a year's GDP lost per point of disinflation $= 2/\beta$ |
| Hysteresis (example) | $u^n_t = 0.5u_{t-1} + 0.5u_{t-2}$ |
