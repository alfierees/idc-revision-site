## National accounts

| Mistake | Fix |
|---|---|
| Counting government purchases from firms in the government's value added | $VA_G = $ wages $+$ rent only; the purchases are firms' sales. They **are** in $G$ |
| Ignoring inventory cleared from last year | $\Delta$inventory $=$ added $-$ cleared, and it enters both value added and investment |
| Treating profit as value added | Profit $= VA -$ wages $-$ rent $-$ depreciation |
| Mixing gross and net | Savings from net output match **net** investment; gross with gross |
| Forgetting imported inputs | They are subtracted from the importing firm's value added |
| "Selling abroad instead of at home raises GDP" | Value added is the same; only $C$ vs $NX$ changes |
| Counting transfers or bond interest as output | They are negative taxes, not production |
| $s_G = G - T$ | $s_G = T - G$; a negative number is a **deficit** |

## Growth rates

| Mistake | Fix |
|---|---|
| Annual average $=$ total growth $\div$ years | $(\text{total factor})^{1/T} - 1$ |
| Subtracting growth rates: $4\% - 4\% - (-5\%)$ | Divide the factors: $\tfrac{1.04}{1.04 \times 0.95}$ |
| "GDP grows faster than population, so living standards rise" | Only in **real** terms; inflation can wipe it out |
| Separating inflation from nominal figures alone | Impossible: you need real GDP or a price index |

## GDP, GNP and trade

| Mistake | Fix |
|---|---|
| $GNP = GDP +$ paid to foreigners | **Minus** paid, **plus** received |
| "GDP above GNP means imports exceed exports" | The GDP-GNP gap is factor income, not trade |
| "Exports equal imports, so savings are zero" | Then $S = I$, not 0 |
| "Imports exceed exports, so savings exceed investment" | The reverse: $S < I$ |

## Loanable funds

| Mistake | Fix |
|---|---|
| More consumption raises investment | Saving falls, $r$ rises, investment **falls** |
| With fixed saving, more demand for funds raises investment | $r$ rises and investment is pinned at $S$ |
| "Same rates at home and abroad means no trade" | It means no net lending; trade can still happen |

## The Solow model

| Mistake | Fix |
|---|---|
| A higher saving rate raises growth forever | Higher **level** of $k$ and $y$; growth only during the transition |
| Steady state means total output is constant | Per-worker values are constant; total $Y$ grows at $n$ |
| Different starting $k$ explains different steady states | Only $s$ (with $A$, $\alpha$, $n$, $\delta$ fixed) does |
| A capital gift or loss changes the steady state | $k$ returns to the same $\bar k$ |
| Emigration with capital raises $k$ | Emigrants take their share: $k$ unchanged |
| Comparing $y$ with $(\delta + n)k$ | Compare **$sy$** with $(\delta + n)k$ |
| "TFP keeps growing" as a Solow assumption | The basic model holds $A$ **constant** |
| A fixed labour force as an assumption | Labour grows at $n$ |

## The Golden Rule

| Mistake | Fix |
|---|---|
| $s_{GR} = \delta + n$ | $s_{GR} = \alpha$; $\delta + n$ is the slope $f'(k_{GR})$ must equal |
| "More saving always means more consumption" | Past $\alpha$, saving more lowers steady-state consumption |
| Golden Rule maximises output | It maximises **consumption** per worker |
| "In steady state, consumption is at its highest" | Only if the steady state is the Golden Rule one |

## Diminishing returns

| Mistake | Fix |
|---|---|
| "More capital, slower growth: inefficient" | Diminishing returns: $MPK$ falls as $K$ rises |
| Fewer workers lowers output per worker | $k$ rises, so $y$ rises; **total** output falls |
| More capital per worker lowers $MPL$ | It raises $MPL$; more **labour** lowers it |

## Balance of payments

| Mistake | Fix |
|---|---|
| Reserves rising as a credit | A rise in reserves is a **debit** (money parked abroad) |
| Aid in goods counted only as a transfer | It is an export too; the grant offsets it |
| Leaving out the unpaid half of an export | The whole export is in the current account; the unpaid half is a capital outflow |
| Buying foreign bonds as a current-account item | Capital account (outflow); only the **interest** is current |
| "The balance of payments records only capital" | It records everything and **sums to zero** |
| A current-account surplus needs a capital surplus | It is matched by a capital deficit or a rise in reserves |
