> In a multiple-choice exam built on cases, most lost points come from **picking the first option that sounds right**. The distractors are designed around a handful of confusions: roles swapped, a correlation treated as a cause, a scale one level off, a real method given the wrong name. Read all four options, and check each against the course's own definition.

## Reading the question

| Mistake | Fix |
|---|---|
| Choosing the first plausible method | If every option is a valid method and the question asks what **can** be done, the answer is **"all the answers are correct"** (Q5, Q6, Q10, Q11) |
| Choosing "none of the answers is correct" as a safe bet | On the sample paper it was never right |
| Picking an option with impressive extras | "Number of citations" and "journal ranking" aren't among the five criteria (Q19) |
| Answering what the case is about instead of what it asks | Q3 is about a dating app, but it asks how to **improve the study**: the sample |

## Variables

| Mistake | Fix |
|---|---|
| Calling the outcome the IV | The **outcome** (success, grades) is the **DV**; what helped or was changed is the IV |
| "Not a variable" for something that clearly varies | If it differs between participants and the study looks at it, it's a variable |
| Mixing up mediator and moderator | Mediator = **how** (the process in the middle); moderator = **for whom / how strongly** (changes the link) |
| Thinking a mediator makes the IV-DV link stronger | Controlling for a mediator makes the direct link **weaker** (partial) or vanish (full) |
| Saying the IV "never changes" | It isn't affected by the other variables; in an experiment the researcher **changes** it |

## Correlation and causation

| Mistake | Fix |
|---|---|
| "X goes with Y, so X causes Y" | Correlation doesn't imply causation; look for a **third variable** or reversed **direction** |
| Calling Q2's coffee link "causal" | A third variable (fewer sugary drinks) explains it: **positive correlational** |
| Reading the slope as the strength | Strength is how **tightly** the points cluster around the line; the coefficient measures it |
| "p < 0.05 means a strong correlation" | It means **significant**; a weak correlation in a big sample can be significant |
| Claiming causation from a survey or a long observation | Causation needs A **before** B, alternatives **ruled out**, and an **experiment** |
| Generalising from a special sample | Excellency students, insignificant results, or support taken after the outcome: you **can't generalise** |

## Methods and designs

| Mistake | Fix |
|---|---|
| Calling any comparison of groups an "experiment" | An experiment **manipulates** an IV; comparing existing successful and unsuccessful founders is not one (Q9) |
| Treating survey and questionnaire as synonyms | **Survey** = the method; **questionnaire** = its set of questions |
| Confusing natural and field experiments | **Natural** = no manipulation, just observation; **field** = a real manipulation in a real setting |
| Thinking a controlled experiment needs a lab | It needs an **experimental and a control group**, identical except for the IV |
| Mixing up longitudinal and cross-sectional | Longitudinal = **one group over time**; cross-sectional = **several groups, once** |
| Saying quantitative research **increases** personal bias | It **reduces** bias in answers; its weakness is that **personal aspects are lost** (Q15) |
| "Quantitative is for natural sciences, qualitative for social" | **False** |
| Expecting qualitative research to generalise | It aims for **versatility** in a small sample, not generalisation |

## Scales and data

| Mistake | Fix |
|---|---|
| Calling a Likert or satisfaction rating interval | The course classifies it as **ordinal** (Q16) |
| Thinking interval values can be non-numerical | Interval values **must be numerical** (Q7) |
| Mixing up interval and ratio | Ratio has an **absolute zero** (money, weight); interval doesn't (temperature) |
| Treating numbered categories as numbers | 1 Morning, 2 Afternoon, 3 Night is **nominal**: the numbers are labels |
| Arguing over whether age is discrete | The slides list it both ways; go by how it's **measured** (whole years counted, exact age measured) |

## Sampling and bias

| Mistake | Fix |
|---|---|
| "Random sampling works only for small, accessible populations" | Random means **every unit has an equal chance** (Q12) |
| Calling snowball sampling random | It's **non-probability**: participants pick the next ones, which biases the sample |
| Thinking bias is visible only after a literature review | A preconceived notion sits **in the wording** ("Most people like to ski…", Q8) |
| Ignoring who didn't answer | **Non-response** bias: unhappy employees skip satisfaction surveys |
| A sample from one place for a worldwide product | Not representative: widen it by age, gender, country (Q3) |

## Questionnaires and interviews

| Mistake | Fix |
|---|---|
| A question asking two things ("type and form") | One thing per question |
| A question that assumes behaviour | Ask first whether they do it at all |
| Skipping the pilot | Pilot on a representative group: understood? purpose? order? length? instructions? |
| Swapping structured and unstructured | Fixed list in fixed order = **structured**; no prepared questions = **unstructured** (Q17) |
| Calling semi-structured interviews rare | They're the **most common** |
| Thinking structured interviews favour validity | Structured → **reliability**; unstructured → **validity** |
| Forgetting the sixth question type | Background, experience, opinion, emotional, knowledge, **sensory** |
| Treating deductive and inductive as the same | Deductive = theory first (top-down); inductive = themes from data (bottom-up) |

## Academic texts and APA

| Mistake | Fix |
|---|---|
| "Non-academic sources can't appear in academic articles" | They can, especially as **data** (a blog as the sample, Q14) |
| Looking for participants in the literature review | They're in the **method** section (Q13) |
| `(Smith & et al., 2010)` or all three names | `(Smith et al., 2010)` for three or more authors |
| Dropping a second author's name | Two authors: **both names every time** |
| Putting the original in the list for a secondary source | `(Levy, 2000 in Cohen, 2020)`: only **Cohen** (what you read) goes in the list |
| Listing an interview or personal communication | **Text only** |
| Using footnotes for references | APA never does |
| Giving both a DOI and a URL, or writing "DOI:" | **DOI only**, formatted like a URL |
| Ordering a list by year first | Surname → initial → single author first → second author → year |
| Citing a source an AI gave you without checking | AI can **fabricate citations**: verify every one (PAIR, Interaction step) |
