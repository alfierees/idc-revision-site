> This course has no formulas. What you need instead is a set of **lookup tables**: how to cite, which scale a variable sits on, which sampling method a case describes, and the exact course definition of each term, because the multiple-choice options often differ by one word.

## 1. APA 7: in-text citations ([[Lec_02-APA Citing and Referencing|Lec 02]])

| Situation | Write |
|---|---|
| One author | `(Cohen, 1988)` or `Levy (1982) argued that…` |
| Two authors | Both, every time: `(Bergman & Rappaport, 2021)` |
| Three or more | First author + et al.: `(Smith et al., 2010)` |
| Several sources at once | Alphabetical, semicolons: `(Becker & Cohen, 1981; Levy, 1979; Smith, 1984)` |
| Year in the sentence | `In 1981, Barnea published…` |
| Same author again soon, same paragraph | No need to repeat the year |
| Two authors, same surname | Add initials: `D. Levy (1983) and G. Levy (1985)` |
| Secondary source | `(Levy, 2000 in Cohen, 2020)`: only Cohen goes in the reference list |
| No author | Organisation or first words of the title: `(United Nations Report, 2010)` |
| Republished work | `(Smith, 1899/2002)` |
| Direct quote | Quotation marks and the page: `(Levy, 2009, p. 4)` |
| Personal communication, interview | In the text only, **not** in the list |
| Footnotes | **Never** used for citing in APA |

## 2. APA 7: the reference list

**Contents:** every source cited in the paper, and only those. You don't label the source type: the format shows it.

**Order of entries**

| Rule | Comes first |
|---|---|
| 1. Surname of the first author, A to Z | `Cohen…` before `Levy…` |
| 2. Same surname, different people: first initial | `Cohen, B. (1989)` before `Cohen, H. (1984)` |
| 3. Single author before the same author with co-authors | `Levy, B. (1988)` before `Levy, B., & Cohen, A. (1969)` |
| 4. Same first author with co-authors: second author's surname | `Levy, B., & Cohen, A. (1983)` before `Levy, B., & Tamir, H. (1967)` |
| 5. Same authors, same order: year; same year: title | |
| 6. An institution as author | Placed by its name |
| Authors listed | Up to **20** |

**Formats**

| Source | Pattern |
|---|---|
| Journal article | Al-Yagon, M., & Mikulincer, M. (2004). Title of article. *The Journal of Special Education, 38*(2), 111-124. |
| Book | Antonovsky, A. (1987). *Unraveling the mystery of health*. Jossey-Bass. |
| Chapter in an edited book | Culbertson, J. L. (1998). Learning disabilities. In T. H. Ollendick & M. Hersen (Eds.), *Handbook of child psychopathology* (pp. 117-156). Plenum Press. |
| Conference paper | Authors (Year). Title. Paper presented at the annual meeting of [body], [place]. |
| Thesis | Author (Year). Title. Thesis submitted for the degree of [degree], [school], [university]. |
| Report, no author | The Central Bureau of Statistics (1985). *Title*. Details (Publication No. 7). |
| Report with author | Author, F. M. (Year). *Title of report* (Report No. XXX). Publisher. |
| Newspaper | Marcus, Y. (2006, October 24). The new era. *Ha'aretz*, Saturday Supplement, p. 24. |

Check: item order, hanging indent, commas, full stops, colons, parentheses, italics, capitals.

## 3. DOIs, URLs and online sources

| Case | Rule |
|---|---|
| What a DOI is | A unique, persistent link; starts with **10**, prefix and suffix split by a slash |
| How to write it | Like a URL; no "DOI:" label |
| Work has a DOI | Always include it, print or online |
| DOI **and** URL | **DOI only** |
| URL, no DOI | The URL, as direct as possible |
| Print, no DOI | Neither |
| Database work, no DOI | Like the print version: no URL, no database name |
| Retrieval date | Only when needed ("Retrieved from") |
| Abstract only | `[Abstract]` after the title |
| Lecture slides online | `[PowerPoint slides]` |
| Encyclopedia, no byline | Entry name first, `(n.d.)` if undated, retrieval date |
| Interview online | `[Interview transcript]`; not online → text only, full date |
| Blog | Post title (not italic) and URL; screen name if no author |
| Wikis | APA warns they can't guarantee verifiability or expertise |

## 4. The four measurement scales ([[Lec_07-Questionnaire Design|Lec 07]])

| Scale | Named | Ordered | Equal intervals | Absolute zero | Course examples |
|---|:---:|:---:|:---:|:---:|---|
| **Nominal** | ✓ | | | | Religious affiliation; time of day 1 / 2 / 3; country |
| **Ordinal** | ✓ | ✓ | | | Likert scale; satisfaction rating; education level |
| **Interval** | ✓ | ✓ | ✓ | | Temperature (can go below zero) |
| **Ratio** | ✓ | ✓ | ✓ | ✓ | Money, weight, height, BMI |

**Decision path for a variable:**

1. Are the values just **names or categories**, with no order? → **nominal**.
2. Is there an **order**, but you can't say the gaps are equal (very / somewhat / not satisfied)? → **ordinal**.
3. Are the gaps **equal**, but zero is arbitrary or values can be negative? → **interval**.
4. Is there a **true zero** (zero means none, and twice as much makes sense)? → **ratio**.

Interval and ratio values **must be numerical**. Discrete data is counted (family members); continuous data is measured (weight, length, GPA).

## 5. Sampling methods ([[Lec_06-Quantitative Data Collection|Lec 06]], [[Lec_08-Qualitative Data and Interviews|Lec 08]])

| Method | Family | How | Watch for |
|---|---|---|---|
| Simple random | Probability | Every unit has an **equal chance** | Needs a full list of the population |
| Systematic | Probability | Every k-th unit from a list | |
| Convenience | Non-probability | Whoever is easy to reach | Not representative |
| Snowball | Non-probability | Participants recommend others | Reaches hidden groups; biased |
| Advertising | (qualitative recruitment) | Notices, forums, group chats | Less population bias; variety not guaranteed |
| Through a gatekeeper | (access) | An authority grants entry | Needed in large organisations |

## 6. Study types and designs

| Type | Goal | Tests a hypothesis? |
|---|---|---|
| Exploratory | Get to know a phenomenon | No: generates them |
| Descriptive | Characteristics, frequencies, strength of a relationship | Correlational only |
| Causal | Does A cause B? | Yes: experimental design |

| Design | Groups | Time | Shows |
|---|---|---|---|
| Longitudinal | One | Repeated, months or years | Change over time |
| Cross-sectional | Several | Once | Differences between groups |

| Experiment setting | IV manipulated? | Where |
|---|---|---|
| Natural | No: observation | Real setting |
| Controlled | Yes, experimental vs control group | Controlled conditions |
| Field | Yes | Real world |
